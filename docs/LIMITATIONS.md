# Known Limitations

Limitations of the **language and the compiler** (`compiler/nurlc.nu`) — the
fixed rules a program must work within. The authoritative grammar is
[`spec/grammar.ebnf`](../spec/grammar.ebnf); the normative language reference
is [`docs/spec.md`](spec.md).

This page is deliberately scoped to language + compiler. Standard-library
feature coverage and gaps (databases, TLS, MQTT, …) are *not* language
limitations — they live with each module (the `stdlib/**` file headers and
[`docs/NETWORKING.md`](NETWORKING.md)) and on the [`ROADMAP.md`](../ROADMAP.md).

**66 soundness holes are known open** ([`MEMORY.md` §6.2](MEMORY.md)).
Each is a use of freed or moved-out memory in safe code, with a fix in progress:

- **agora #242: a join or a value block bound by `:` and then handed on
  by name, in nine remaining shapes.** The common ones are closed: a `:`
  binding of a join takes the owner its arm selects, an `inout` parameter
  takes a binding owned per path, a block ending in a fresh call owns its
  result. Nine shapes still fault, each the elaborated twin of a closed
  probe ([`twins.txt`](twins.txt)): the binding does not inherit what its
  producer lends — a call in an arm lending a local, a field or a view of
  an inner local, a value a `;` defer releases. Until #222 closes them,
  hand such a value on directly (`^ ? c a b`) instead of through a binding.
- **agora #280: a field a `sink` took, used again by a route the
  check does not see.** A field a `sink` took (`( take . h buf )`) is refused
  while it is empty when it is read, bound, handed on whole with `h`, or
  left empty at an `inout` exit. So are a take inside a loop, read on the next
  round or after it, and the taken field handed back itself (`^ . h buf`,
  `^ @ Holder { . h buf }`, `= h @ Holder { . h buf }`; agora #351). These
  are still accepted, and run into the null handle or freed memory: a path
  under or over the taken one (`. o a`
  taken, then `. . o a b` read, or the reverse); `h` handed on whole by
  `^ @ Outer { h }`, `^ ? c h h2`, `= h2 h`, a value block `{ h }` or
  `= . g buf . h buf`; a closure made after the take, `h` captured and
  returned, or a closure's own `inout` parameter; a `% Drop` destructor that
  reads the taken field; and an `inout` callee that panics between the take
  and its refill, caught by a `recover` closure that captured the struct.
  Until the fix ships, give the field a value right after the take
  (`= . h buf ( vec_new [u] )`), or hand the callee a copy
  (`( mem_dup . h buf )`) and keep the field.
- **agora #366: an owner's old value whose hand-over has no key: kept
  back (a leak) on a lend path, freed under its borrower on an owned one.**
  A `: ~` owner given a new value drops its old one, and hands it to a live
  borrower that holds it instead: a `??` payload, or a `: ?T prev cur`
  cursor. That hand-over tells the old value apart by a key: a String's or a
  Vec's buffer, a record's first String or Vec field, or an enum's first
  payload where it is the value's own pointer. An option payload, a library
  handle such as a Box, a record whose first owned field is an option or an
  enum without such a key in every variant, and an enum with a variant whose
  first payload is a number or a view while a later one owns memory
  (`A i String`) have none. Given a value a call lends out of another owner
  (`= o ( vec_get [Rec] rs 0 )`), such an owner keeps its old value back and
  never releases it, as before #317's fix (agora #361 ended the
  use-after-free that dropping it caused). Given a fresh value or a `?` join
  instead (`= o ( mk )`), it still frees the old value under the borrower
  that reads it, and an option-typed alias of an option owner
  (`: ?String p ( id o )`) makes clang reject the program. Until the fix
  ships, give such an owner its new value outside the borrower's scope, or
  bind the borrower to a copy (`( mem_dup … )`).
- **agora #378: an option owner given a lend inside a closure, out of a
  capture, through a forwarder defined above the closure.** `\ → v { = o (
  first vs ) }`, with `vs` and `o` both captured and `first` handing back `(
  vec_get vs 0 )`, keeps `o`'s old value back instead of freeing it, so it
  leaks. The closure cannot tell whether the captured `vs` views `o`'s own
  value (a field of its payload, say), so it keeps the safe answer. Defined
  below the closure, the forwarder is clean. Until the fix ships, make the
  assignment outside the closure, or free the old value first (`= o @
  ?String { F }`).
- **agora #382: a panic under `recover` between a holder's store of a
  callee local's view and its repoint.** `= w @ W { ( string_data b ) }`
  then a call that may panic, then `= w @ W { … }`: the unwind releases `b`
  and hands `w` back to the `recover` caller still viewing it, when `W` has
  no `% Drop` (#284 covers Drop holders). Until the fix ships, don't call
  anything that may panic while an `inout` holder views a local.
- **agora #384: a handle's own drop hook that reads a view.** A struct with
  an `S_drop` hook of the program's own (`@ H_drop sink H h → v { … }`) is
  taken to read only what it owns. A hook that reads one of its view fields
  (`( nurl_println . h v )`), given a view of a binding declared after the
  holder, reads freed memory where the scope ends. The same goes for a
  program's own generic handle (`: Holder [T] { s name T x }`). Until the
  fix ships, declare a view's source before such a holder, or keep the hook
  from reading view fields.
- **agora #387: a second reader of a field, after the field is replaced.**
  With `: String g1 . o name` and `: String g2 . o name`, replacing `. o
  name` hands the old value to g1, the first reader, and leaves g2 a view
  of it. Nothing in the checker knows that: handing g2 to a `sink`
  (`string_free g2`), returning g2 out of the function, or reading g2 after
  g1 is consumed or reassigned all compile and reach freed memory. Until
  the fix ships, keep at most one reader of a field across a replace of
  that field, or copy the second one (`mem_dup`).
- **agora #395: a store through a borrow that #292 does not follow to
  its owner.** Inside a closure, through a borrow of a capture (`: ( Vec s
  ) w ( id vs )  ( vec_push [s] w ( string_data loc ) )` with `vs`
  captured); with an unbound call as the container (`( vec_push [s] (
  vec_at [( Vec s )] vv 0 ) … )`); or through an option payload cursor
  (`?? ov { T w → ( vec_push [s] w … ) }`): the owner never learns it holds
  the view, and read after the source ends it reads freed memory. Until the
  fix ships, bind the container to a name outside closures before storing a
  view into it, and keep the view's source alive as long as its owner.
- **agora #424: a borrow of a `??` payload, and the scrutinee handed to a callee that clears it.** Inside `?? o { T inner → … }`, a borrow of an element of `inner` survives `( clr o )`, where `clr` clears what the option's payload holds, so reading it afterwards is a heap-use-after-free. The same goes for an enum payload, and for named callees as for closures. Until the fix ships, end the payload's borrows before passing the scrutinee on.
- **agora #427: an option owner given what a call may hand back of its
  own value, where nurlc has no lend fact for the call at that line.** `=
  o ( id ( pick o other k ) )`, a generic or `dyn` callee, a callee defined
  below the call, mutual recursion, or the call inside a value block (`= o
  { ( pick o other k ) }`): the old value is dropped by its own flag, so the
  run that hands `o`'s own value back frees it under `o`
  (heap-use-after-free). The direct form `= o ( pick o other k )` is
  refused (#412). Until the fix ships, give `o` a copy of such a call's
  result (`( mem_dup … )`) or bind the result to a new name.
- **agora #428: a change made in place by a route that does not reach the
  owner.** A view of an option's payload, or a slice of a Vec, stays live
  while the payload or the buffer is changed through a `: ~` copy of a
  match payload (`?? oh { T q → { : ~ H c q ( string_push_str . c name … ) }
  }`), a closure, an option held in a struct field or in another payload,
  a user enum's payload, a `( vec_at … )` payload, or a chain of copies of
  the owner's handle (`( id ( id vs ) )`, `: ~ w2 w`, a join of copies). A
  later read of the view is of freed memory. Until the fix ships, change
  an option's payload, or grow a Vec, through the owner's own name or a
  direct `??` over it while a view of it is still read.
- **agora #445: a closure called with a binding it replaces, by any route but a direct call.** `( c o )`, with `c` giving its capture `o` a new value, is refused. Handing `c` and `o` to a function that calls one with the other, calling a copy of `c`, a literal passed inline, a nested closure doing the assignment, or an argument that is a view, an element or a payload of `o` are not refused, and the parameter is read after it is freed. Until the fix ships, pass the closure a copy that owns its data.
- **agora #450: an owner given a part of its own value, or a value that
  shares part of it, while nurlc takes the result for another value.** `=
  o ( first o )`, with `first` handing back an element of o's own Vec
  field through a generic it calls, or a `: ~` cursor copy of a struct
  whose first field was replaced: o's old value is released with the part
  inside it, and reading o reads freed memory. Until the fix ships, take
  the part out of the owner into a new binding (or copy it, `mem_dup`)
  before giving it to the owner.
- **agora #460: two `??` payload bindings of one enum value, a change through one.** `: E e @ E { Some inner }` matched twice, `Some xs` and then `Some ys` inside it. `xs` and `ys` are one Vec. `( vec_clear [String] ys )` ends no borrow taken through `xs`, so a String read out of `xs` before the clear is freed memory after it: a heap-use-after-free. A closure that clears its capture's payload (`\ → v { ?? e { Some xs → { ( vec_clear [String] xs ) } None → {} } }`), run while the caller holds a borrow through its own payload binding, is the same hole. Until the fix ships, match an enum value once and clear the Vec through that one binding.
- **agora #462: a function binding a lent element of its parameter, or an enum payload of one, and handing the binding back.** `@ g ( Vec Conn ) cs → Conn { : Conn c ( vec_at [Conn] cs 0 ) ^ c }`, with Conn a `% Drop` type, gives its caller an owner of what `cs` still owns, so both release it: a double drop. The direct `^ ( vec_at [Conn] cs 0 )` is lent back and runs clean. An enum parameter's payload, `?? e { Has c → { ^ c } … }`, is the same. Until the fix ships, hand back the call itself (`^ ( vec_at … )`) rather than a binding of it.
- **agora #464: a temporary argument freed right after the call while the callee's result views it.** `( show ( mk ( string_from … ) ) )`, with `mk String line → Tok` handing back an enum or struct that holds a view of its parameter (`Tok { Word s … }` given `( string_data line )`), drops the temporary after the call, and the result reads freed memory, even inside one statement. Until the fix ships, bind the argument to a name first.
- **agora #466: an `inout` view parameter kept in a second holder, an `s` global or a thread.** `@ put inout ( Vec s ) first inout ( Vec s ) h inout s x → v { ( vec_push [s] h x ) }` stores a view of the caller's string into the caller's other holder without tying that holder to the string, so it is read after the string is freed. The same goes for a field of an `inout` struct of views, an `s` global and a spawned thread. Until the fix ships, pass the view as a plain (not `inout`) parameter.
- **agora #467: a returned closure that captured a holder given a view of a parameter.** `@ mk String s → ( @ v ) { : ( Vec s ) h ( vec_new [s] ) ( vec_push [s] h ( string_data s ) ) ^ \ → v { … h … } }` hands back a closure tied to nothing, so calling it after the caller's String ended reads freed memory. A captured struct of a view and an owned String filled from the parameter is the same. Until the fix ships, capture a copy of the text (a String the closure owns) rather than a holder of views.
- **agora #469: a closure that captured an owner of views by value, run on another thread or stored into an owner that adopts it.** A closure capturing a `( Vec s )` of views (or a `vec_clone` of one) is spawned with `thread_spawn`, or stored into a struct literal or a container (`@ H { \ → i { … views … } 0 }`), and the views go with the copy unchecked: the string they view can be freed while the thread or the owner's closure reads it. Until the fix ships, give the thread or the owner Strings it owns (copies) or an `Arc` share, not a Vec of views.
- **agora #472: an iterator yields copies of what it captured.** `( iter_collect [s] ( iter_from_vec [s] t ) )`, `iter_find` or `iter_fold` over it, `iter_map` collected, a direct `( it 0 )`, or a function of your own draining a closure parameter hands back the views the iterated Vec held with no tie to the string they view, which can be freed under them. Until the fix ships, iterate with `~ x t` or `vec_at`, or keep the strings alive past the result.
- **agora #475: the keep rule and the `inout` store for a `!i String`, a `? ?String` or a `!( Rc String ) String`.** `= o ( f o k )`, where `f` hands back its first argument on one run and something else on another, and the store of such a value through an `inout` slot, have no key for these three types (a result whose Err owns a String while its Ok is a number, an option of an option, a result of an Rc share): the old value is released while the new one still is it, and it is read after its release (heap-use-after-free). Until the fix ships, give such a binding the result of a call that may hand it back through a fresh binding (`: … r ( f o k )`) and move `r` in once `o` is no longer read.
- **agora #479: a copied closure that views a local, a closure body handing a `sink` a value derived from its capture, and a statement-form match arm returning a closure over a borrowed field.** `( mem_dup c )` of a bound closure that views a local outlives the local. A closure body that hands a `sink` a local copy of its capture, a part read out of a capture's payload through a field, a vec element or a borrowed parameter, or an inout capture, frees it twice on a second call or at the env's drop. `?? o { T s → { ^ \ → … s … } }` with `o` a parameter's field frees the caller's field twice. Until the fix ships, copy a capture before handing it to a `sink` in the body (`( eat ( string_clone x ) )`), return the closure literal as the arm's value rather than from a block, and don't copy a closure that views a local.
- **agora #481: a `dyn` impl that calls its own method through a dyn field.** An impl whose method hands back the result of the same method called on a `dyn` field, with its view arguments swapped (`^ ( toks . self child b a … )` beside an impl that views its first argument), answers its result's views as nothing. Its walk is parked and the virtual callee has no answer yet, so the call reads as one that hands back no view, and a caller that frees the second argument while it reads the result reads freed memory. Until the fix ships, hand the arguments down in the order the result views them, or call a named helper instead of the method through the field.
- **agora #487: a bare `s` view handed back through a `??` value join.**
  `^ ?? ( vec_get [String] p 0 ) { T e → ( string_data e ) F → `` }`: the
  arm's view of the payload `e` is a view of p's element, but the function's
  lend answer does not say so, and a caller that clears p while holding the
  result reads freed memory. (The `?` join, its else arm, and a `??` payload
  view returned from inside an `if` are refused since the fix for #487.)
  Until this is fixed too, bind the payload's view first and hand that back,
  or hand back a copy (`string_from`).
- **agora #488: a field given a new value through a `~` loop's struct element.** `~ p ps { = . p name ( string_from … ) }` writes into a per-iteration copy of the element: the Vec keeps the old value and the new String leaks; an `i` field written so is lost, and a `vec_at` binding of a struct does the same. Until the fix ships, give an element's field its new value through the container (`vec_put`, or rebuild the element), not through the loop element.
- **agora #489: an `unsafe` function handing back a view of its `~` loop's element over a parameter.** Its walk has no source expressions, so it answers nothing about that view, and codegen's lend answer does not see loop elements: a safe caller can clear the container and read freed memory. Until the fix ships, do not hand a loop element's view back out of an `unsafe` function; return it from a safe one, or return an owned copy.
- **agora #494: a container handed to a `sink` parameter together with a borrow of its element.** `( eat_then_read t e )`, where `eat_then_read` takes `t` as `sink` and frees it, and `e` is `( vec_at [String] t 0 )` (or a closure over `e`, or over a `~` loop's element of `t`): the callee reads `e` after it freed `t` (heap-use-after-free). The exclusive-call check does not count a `sink` argument as one whose elements the callee drops. Until the fix ships, read the borrow before the call, or pass a copy (`string_from`, `mem_dup`) beside the container.
- **agora #495: a struct element of a parameter, bound and handed to a callee that clears a field of it.** `@ top ( Vec H ) hs → v { : H e ( vec_at [H] hs 0 ) ( wipe e ) }`, with `wipe` clearing `. h rows` of its `H` parameter: `top`'s summary records no drop of `hs`'s elements (drop summaries are per parameter, and a struct read out of one makes no edge), so a caller's view into that field's elements is read after the clear frees it. The inline spelling `( wipe ( vec_at [H] hs 0 ) )` is refused. Until the fix ships, hand the callee the field itself (`( vec_clear [String] . e rows )` in `top`), or take the view after the call.
- **agora #545: an owned slice moved on, given a parameter, or read after a move.** A slice binding that owns its buffer (`: [i q ( mk )`, `: ~ [i d [i | 1 2]`) and is then handed to an aggregate (`^ @ Box { Full q }`, `^ @ Holder { q 1 }`) or copied (`: [i r q  ^ r`) is released by the binding and by its new holder (heap-use-after-free). `= d p` with p a parameter keeps d owning, and d's drop frees the caller's buffer. After `= e a`, a can still be read, and the next `= e [ … ]` frees it under that read. Through an `inout [i` parameter, `= p q` or `= p [ … ]` releases a buffer twice. Until the fix ships, keep a buffer that is handed on in a `Vec` rather than a `[T` slice, and never assign a parameter, or another binding you still read, to an owned slice binding.
- **agora #557: a borrow through one `??` and a change of the payload's field in another.** `: ( Vec S ) k ?? ev { A p → . p a B q → . q a }`, a borrow of an element of `k`, then `?? ev { A p → { ( vec_clear [S] . p a ) } … }`; or a borrow out of an arm's `( vec_at [S] . x a 0 )` followed by a clear through `: j ?? oh { T x → . x a F → . h b }`: the second match's change of the payload's field ends no borrow taken through the first, which then reads freed memory (heap-use-after-free). Until the fix ships, read the borrow before the second match, or change the field inside the same match that took the borrow.
- **agora #560: `^` of a lend of a local reached through a direct slice call, another slice maker or a re-pointed / aliased slice, a payload field bound first, an option field of a payload, a vec_pop payload, or a closure.** `^ ( slice_at [String] sl 0 )` with sl a slice of a local Vec, `: String t . p s  ^ t` of a vec_get payload of a local, `?? . r o { T e → ^ e }` of an option field of one, and the like: the element goes to the caller as its own while the local's drop frees it (heap-use-after-free). The binding of a parameter's element (`: ( Vec String ) v ( vec_at pvv 0 )`) then handed back through vec_get is a double free. Until the fix ships, bind the element and hand it back by name from a vec_get / slice_get payload (`?? ( vec_get … ) { T e → ^ e }`, which is taken out or copied), or hand back a copy (`( string_clone e )`).
- **agora #570: a closure parameter cleared through a binding.** A closure `\ ( Vec S ) v → v { : ( Vec S ) j v  ( vec_clear [S] j ) }` (or `{ v }`) called with `. h a` ends no borrow its caller holds of that field, which then reads freed memory (heap-use-after-free): a closure parameter's derivations are not recorded. Until the fix ships, clear a closure's parameter by its own name (`( vec_clear [S] v )`).
- **agora #575: a heap-valued value block's locals keep their names after the block.** After `: String e { : String s … }`, every later statement's `s` is the block's own `s`, not the outer one: an assignment or a read meant for the outer binding reaches the block's local, and `: __el { : String s … s }  = s __el` reads freed memory (heap-use-after-free). Until the fix ships, do not reuse an outer binding's name for a local inside a value block. The same leak makes `= v { : ~ ( Vec i ) v … v }` in a loop body, or with `v` an `inout` parameter, hand the block's `v` to nobody (heap-use-after-free); give the local a name of its own there too.
- **agora #580: a `~` loop over a container lent out of another, grown through another borrow of it.** With `: ( Vec i ) b ( vec_at [( Vec i )] vv 0 )`, a `( vec_push [i] ( vec_at [( Vec i )] vv 0 ) … )` inside `~ x b { … }` (or the same through a second borrow, or two lends deep) moves the buffer the loop walks, and the loop reads its next element from the old one (heap-use-after-free). The loop's borrow covers a container an owner holds itself (a binding, a field path, a copy of its handle), not one a level below it: the walk's element mark is one level deep and cannot tell that row's buffer from another row's, or from a String inside it. Until the fix ships, do not grow a nested container inside a loop over a borrow of it; walk it by index (`~ < k ( vec_len … )` with `( vec_at … k )`) instead.
- **agora #601: a cursor of a container that reaches a growth through a struct literal, or a `~` loop over an Rc's payload grown through another handle.** With `: ~ ( Vec T ) cur t`, growing through `. q items` after `: ~ H q @ H { cur 0 }` moves `t`'s buffer under a `~` loop over `t` or a view of it (heap-use-after-free); the direct spellings — the cursor itself, a join of cursors, a second parameter, a closure over it — are refused. And a `~` loop over `: ( Vec u ) pv ( rc_get r2 )` goes on after the payload is grown through `r`, a clone of `r2` (`( vec_reserve ( rc_get r ) 4096 )`, or a helper handed `r`): the same-Rc rule ends the views taken through `r2`, not the loop's walk. Until the fix ships, grow a container only by its own name or a plain cursor of it while a loop or a view of it is live, and do not change an Rc's payload through another handle inside a loop over it.
- **agora #604: within one statement, a call's result that views a binding, or a view read with no call, used after a later call ended what it views.** `( two ( string_data s ) ( cz fs ) )` — the first argument's result waits while `cz` clears what it points into — and `: s w ? == 0 ( cz fs ) v ``` with `v` a view of `fs`'s element read freed memory; the forms that hand a BINDING to a call after another call ended it are refused. Until the fix ships, bind a view to a name on its own line before a call that may change what it views, and do not read it in the same expression after such a call.
- **agora #626: `= s { : String s … s }` into an `inout` parameter, or in a loop body.** A value block whose tail is a block-local with the assigned name is right for a local target outside a loop (#562); with `s` an `inout` parameter (a String or a Vec), or with the assignment in a loop body, the target reads freed memory afterwards (heap-use-after-free). Until the fix ships, give the block's local another name.
- **agora #628: a value block ending in a call, where its result is not a `:` binding's or a local assignment's.** In a loop condition, assigned to an `inout` parameter, with a tail call that lends a temporary past a block local, or as a join of block locals handed to a `sink`, the result (or the binding not selected) is never released: a leak once per run of the statement. Until the fix ships, bind the block's value with `:` first.
- **agora #629: a value block's tail binding consumed inside the block, beside an outer binding of its name.** `: String e { : String s … : i n ( eat s ) s }` with an outer `s` in scope: the tail's read is judged against the outer `s`, which nothing moved, so the consumed value is handed on (heap-use-after-free); without the outer `s` it is refused. The same resolution refuses a correct block whose tail is its own fresh binding after the OUTER one was moved. Until the fix ships, give a value block's bindings names of their own.
- **agora #631: a mutable second name of an owner, changed, then handed on.** `: ~ P e p`, then `= . e name …`, then `^ e` reads freed memory in the caller; `: ~ String e s`, then `= e …`, then `( eat e )` leaks the new value. (The same task holds a compiler hang on nested value blocks whose bindings reuse one name in their initialisers.) Until the fix ships, change an owner through its own name.
- **agora #637: a closure a `;` defer calls, bound where the binding is made more than once.** A capturing closure bound in a loop body (or in a value block in one) with a `;` defer that calls it keeps every round's environment but the last until the function's cleanup, which releases one: the others leak. The same for `^ { : ( @ i i ) f \ … ; { ( f 1 ) } f }` (one environment) and for a closure bound in a value block that is a loop condition (each round's but the last). Separately, `: T w v` in a generic instantiated at a closure type is refused as "use of undefined identifier 'w'". Until the fix ships, bind such a closure once, outside the loop.
- **agora #638: closures through value blocks, the rest of #627.** Four accepted shapes that use a released environment: a closure over a value block's own String that leaves the function as the block's value (`^ { : String s … : ( @ i i ) f \ … s … f }`; the plain `^ f` is refused); a block that both assigns its closure to an outer binding and hands it out, when the outer binding is later reassigned; `= a { … a }`, a block whose tail is the assignment's own closure target; and `= a { : ( @ i i ) h \ … h }` while a `;` defer that calls `a` is armed. Until the fix ships, bind a block's closure with `:` and do not assign it elsewhere inside the block.
- **agora #643: a field given a new value through a by-value struct parameter, or through a struct a closure captured.** `@ rename App a → v { = . a name ( string_from … ) }` (nurlc warns that the caller does not see the store) and `\ i k → v { = . a name ( string_from … ) }` over a captured `App a` (no warning) write into the function's own copy: the caller keeps the old value and the new String, Vec or handle is never released; a scalar field written so is lost. Until the fix ships, take the struct `inout`, hand the new value back, or keep what changes in a handle-typed field.
- **agora #647: a view of a struct's field across a call that grows that field through a handle read out of its parameter.** `: s view ( string_data . app name )`, then `( ext app )` where `@ ext App a → v { : String nm . a name ( string_push_str nm … ) }` (or one that grows `( nameof a )`, an accessor's lend of the field): the call moves the field's buffer and `view` reads the old one (heap-use-after-free). A view of the whole binding, and a callee written with the field path itself (`( string_push_str . a name … )`), are refused. Until the fix ships, take such a view after the call, or grow the field by its path.
- **agora #656: a closure that changes a by-value parameter it captured.** `@ w ( Vec u ) x → v { : ( @ v ) c \ → v { ( vec_reserve [u] x 4096 ) } ( c ) }` — or the literal run by a helper, calling a function that grows `x`, or growing a field of a struct parameter — tells its caller nothing: a `Slice` (or any view) the caller took of the argument before `( w xs )` reads the moved buffer afterwards (heap-use-after-free). A closure handed BACK does the same when the caller runs it: `@ mk ( Vec String ) x → ( @ v ) { ^ \ → v { ( vec_clear [String] x ) } }`, then `: ( @ v ) c ( mk xs )`, a view of `xs`, `( c )`. And where several threads reach the value — the callee of a closure they share, or of an Arc's reader — such an inner closure changes it with no lock, unseen by the thread rules. The same change written in the function's own body is refused at the call. Until the fix ships, change a parameter in the function's body rather than in a closure over it, and take views of an argument after the calls (and after running a closure made from it).
- **agora #657: an Arc's payload changed through a closure.** The reader of an Arc that several threads hold calls a closure VALUE on the payload — `: ( @ v App ) g \ App y → v { ( vec_push [i] . y v 1 ) }`, `( g ( arc_get [App] mine ) )` — or runs a closure that captured a bound payload view, `: App p ( arc_get [App] mine )`, `: ( @ v ) c \ → v { ( vec_push [i] . p v 1 ) }`, `( c )`: both are accepted, and every thread grows one buffer with no lock (heap corruption). A named function in the closure's place, and the change written as a statement, are refused. Until the fix ships, keep what several threads change in a `Locked`, an `Atomic` or a `Channel`, and do not hand an Arc's payload to a closure that changes it.
- **agora #663: a returned value block, the rest of #649.** `^ { { p } }` — a returned block whose tail is itself a block — hands back a parameter's own buffer (dropped by caller and callee) or a cursor of a block local (freed memory). A returned block whose tail binding is or holds a view (`^ { : String t … : s d ( string_data t ) d }`, a closure over a block local, a struct of views of one) is accepted where the unblocked `^ d` is refused, and the caller reads freed memory. And `^ ( f { : String t … t } )`, where `f` lends its argument, returns a lend of the block's binding uncopied. Until the fix ships, bind a block's value with `:` and return the binding by name.
- **agora #664: an owned slice has no drop flag.** Who releases a slice buffer is decided at compile time, so a second name for one handed back (`: [i c a  ^ c`, `^ ? k a b`, `^ . q xs`), a conditional move (`? k { = dst src } {}`) and an assigned join of a fresh slice and a binding release the buffer twice or leave the caller reading freed memory; a bound join's fresh path, a slice from a closure call, slices held by elements or payloads, and a local slice read by a returned slice literal are released by nobody. Until the fix ships, give each slice one owning binding, hand back that binding by name, and copy rather than alias.
- **agora #665: a struct holding a closure, pushed into a `Vec` kept in an `Arc`, and the closure run by several threads.** The capture set of the closure does not follow the struct into the `Vec`, so the rule for closures several threads may run does not see it: a closure that gives a capture away, or changes a captured `Vec`, is accepted, and the threads release the one value twice or race on it. Until the fix ships, keep a closure that several threads run in an `Arc` of the struct that holds it directly (that spelling is checked), not in a container inside the `Arc`.
- **agora #667: `= b x` where `x` owns its value on some paths only (`: ~ String x ? c ( string_from … ) lent`), and the panic journal after a handover by name.** Assigning such a binding to two others and then giving it a new value leaves one of them reading freed memory (a `String`, and the same through a `?String`); and a binding whose value was handed over by name and that was then given a new value is not released when a panic unwinds under `recover` (a leak). Until the fix ships, make such a binding own its value on every path (clone the lent arm), and do not hand a binding over by name and reassign it inside code that may panic under `recover`.
- **agora #668: a `: ~` binding of a value block whose tail is the block's own binding, handed to a `sink`; a cursor `: ~ w u` given a new value and then handed to a `sink`; a tail named like the binding; a raw `s` tail handed back.** `: ~ String e { : String s … s }` then `( eat e )` reads freed memory; `: ~ w u`, `= w fresh`, `( eat w )` leaks `u`'s value; `: String s { : String s … s }` then a `sink`, and `: String e { : String s …  : String t { s }  t }` then a `sink`, read freed memory; `: s e { : s t … t }  ^ e` hands back a freed string. Until the fix ships, bind the block's value with an immutable `:` under a name of its own and one block deep (that spelling is right since 0.91.0), or build the value outside a block.
- **agora #669: a borrowed `% Drop` value still taken for owned through a nested generic identity, an `=` into an owning binding, a stored binding of a parameter, or a loop element handed to a `sink`.** `^ ( gid [T] ( gid [T] p ) )`, `= best x` inside a `~` loop followed by `^ best`, `: T e p  ( vec_push [T] out e )`, and `~ x v { ( eat x ) }` with `eat` a `sink` each release the value twice; a literal with a nested literal that lends beside a fresh field leaks the fresh field. Until the fix ships, hand a loop element or a parameter on only by the direct spellings (`^ x`, one generic call), and clone a value before storing it elsewhere or handing it to a `sink`.
- **agora #677: a part of a parameter handed back on one path while another path hands the parameter to a `sink`; a payload of a local plain enum handed back through a binding, a generic call or a struct's field; a `% Drop` literal handed straight to a function that only reads it.** The function releases the parameter on every way out and the caller reads freed memory (a `~` loop element, a plain enum's payload); `: String t s  ^ t` in an arm of a local enum hands back a string the enum then frees; `( show @ D { … } )` never runs `D`'s destructor and leaks its fields. Until the fix ships, do not hand a parameter to a `sink` in a function that also returns a part of it, return a payload of a local enum with `^ s` directly (or clone it), and bind a `% Drop` literal before passing it to a reader.
- **agora #682: a payload view kept in a local Vec.** A `( Slice T )` over an Arc's payload pushed into a local `( Vec ( Slice T ) )` (or a Vec of structs holding one) and read back with `vec_get` / `vec_at` is no longer known to be a view of the payload, so `( slice_put w 0 x )` on it is accepted and changes what every thread holding a clone reads (a data race; a double free when the element owns memory). Bound directly, or inside an option or struct local, the same write is refused. Until the fix ships, never write through a view of an Arc's payload that went through a container; keep changing state behind an Atomic, a Mutex or a Locked inside the Arc.
- **agora #686: a growing closure run under another name.** `: ( @ v ) c \ → v { ( vec_reserve [u] xs 4096 ) }` run as `( c )` ends the views of `xs`, but run through a copy - `: ( @ v ) d c  ( d )`, `= d c`, `? k c c0`, a block value `{ c }`, a literal chosen by a ternary or match arm, one assigned inside a `?` arm or in an earlier round of a loop - it does not: a slice of `xs` taken before the run reads a moved buffer (use-after-free). Until the fix ships, run such a closure under the name its literal was bound to and take views of what it captured only after it ran.
- **agora #689: the crossing check and a sealed handle over an Arc.** A program's own sealed handle (an `unsafe` drop hook) that keeps its state in an `( Arc Impl )` and writes it through `arc_ptr` is one unsynchronised state, but the run-time crossing check counts only `( Shared T )` blocks: `: Tally mine ( Tally_share t )` then a thread capturing `t` crosses with `mine` left behind, where the same handle over a `Shared` panics at `thread_spawn`. Both threads then change one Vec (double free). It takes the program's own `unsafe` marker to reach: the handle's hooks and its `arc_ptr` writer are `unsafe` functions. Until the fix ships, keep a handle's changing state in an `Rc` or a `Locked` with safe hooks, or in a `( Shared T )`, never behind `arc_ptr`.
- **agora #696: a handle local changed in a loop before it is given a captured field.** In a closure several threads run (or a function an Arc's payload is handed to), a mutable local changed first and re-pointed afterwards — `~ … { ( vec_push [i] c j ) = c . a v }` — is judged where the call stands, when `c` reaches nothing shared yet; `= c . a v` makes `c` a second name of the capture's buffer, so the loop's next round changes it, and the thread rules accept the closure: threads running it grow one plain Vec with no lock. The straight-line order (assign, then change) is refused. Until the fix ships, do not give a mutable local a value read out of a capture or an Arc's payload inside a loop that also changes the local; take a copy (`vec_clone`, `string_clone`) or keep the shared state behind a `Locked`.
- **agora #717: a closure stored into the caller's container by a helper.** A closure's type does not say what it captured, so the thread rules follow each closure from where it was built — within one function. `@ add ( Vec ( @ i ) ) makers ( Rc i ) theirs → v { ( vec_push [( @ i )] makers \ → i { … ( rc_clone [i] theirs ) … } ) }` puts a closure over an `Rc` into its caller's `Vec`, and the caller then knows of no capture in it: the `Vec` is captured by a `thread_spawn` closure, the thread runs the element, and two threads count one unsynchronised reference count (a use after free). The `vec_push` written in the caller, and the element read out and captured by itself, are refused. Until the fix ships, a container of closures that will cross to another thread must be filled in the function that hands it over, not by a helper, and with the closures themselves (a struct or an option holding one: agora #718).
- **agora #718: a closure stored in a struct or an option on its way into a container.** A closure's type does not say what it captured, so the thread rules follow each closure from where it was built, and three stores are not followed: a struct holding the closure pushed into a `Vec` (`( vec_push [H] hs @ H { \ → i { … ( rc_clone [i] r2 ) … } 1 } )`), a closure field assigned after the struct was built (`= . h f \ → i { … }` in a function that hands `h` back), and an optional closure in a `Vec` (`( Vec ?( @ i ) )`). The holder is then taken for one whose closures captured nothing: it is captured by a `thread_spawn` closure, sent on a `Channel` or put in an `Arc`, the other thread runs the closure, and two threads count one unsynchronised reference count (a use after free). The closure pushed bare into a `( Vec ( @ i ) )`, and the struct literal bound to a name and captured, are refused. A closure whose signature names an `Rc` (`( @ ( Rc i ) )`) is refused in a struct field whatever it captured, which covers these stores for such closures and refuses one that captured nothing. Until the fix ships, a closure that captured an `Rc`, a `Cell` or a share handle must not be put into a container inside a struct or an option, nor assigned to a field of a struct that then goes to another thread.
- **agora #719: a closure run by several threads that changes a `% NotSync` instance inside what it captured.** The rule for a closure several threads run at once (one kept in an `Arc`) excuses a change made through a capture whose type synchronises itself, and asks that of the captured value's type alone: with `unsafe % Sync W { }`, `% NotSync ( W i ) { }` and `: App { ( W i ) wi ( W b ) wb }` asserted `unsafe % Sync`, a closure that captured an `App` and hands `. app wi` to a function that grows its plain `Vec` is kept in an `Arc` and run by eight threads (a double free). Handing the `( W i )` itself to the threads is refused, and so is the same change reached through an `Arc`'s payload. It takes the program's own `unsafe % Sync` on the holder. Until the fix ships, a type asserted `unsafe % Sync` must not hold an instance the program marked `% NotSync`.
- **agora #736: closures that change an Rc's payload through a capture's field, from a struct field, or from a function's result.** A closure capturing a struct `h` that runs `( rc_set . h a … )`, a closure capturing `r` stored in a struct field and run by a helper, and a closure a function returns over a clone of its argument, each run beside a slice taken through `r2` (a clone of `r`), leave that slice dangling (heap-use-after-free). Until the fix ships, take views through an Rc's other handles again after running a closure that may change its payload.
- **agora #738: a trait object holding a share.** A `( dyn Wiper @ G { r } )` whose method clears `( rc_get . g r )` leaves a view taken through `r2`, a clone of `r`, dangling (heap-use-after-free): the walk that asks which Rcs a value reaches gives a `%Trait` object none. Until the fix ships, take views through an Rc's other handles again after calling a method of a trait object that may hold a share of it.
- **agora #766: a value whose `% Drop` changes a shared Rc's payload, released where no call is.** With `: H { ( Rc ( Vec u ) ) a }` whose `drop` clears and shrinks `( rc_get . h a )`, and `r2` a clone of `r`, a slice of `( rc_get r2 )` dangles once an `@ H { r }` is released at a block's end, as the old value of `=`, as a statement's discarded result, or by a `sink` helper that lets it go (heap-use-after-free). Until the fix ships, take the view again after a value whose `drop` changes a payload is released, or release it through a library dropper (`vec_clear` of a `( Vec H )` is refused).
- **agora #774: a `~` loop over an Rc payload of numbers, reset through another handle inside it; a payload view written into an `inout` parameter.** With `r2` a clone of `r` and `pl` its payload, `~ x pl { ( wipe r ) … }` reads freed memory on the next round when the elements are numbers (heap-use-after-free): the loop's cursor over `pl` outlives `pl`'s end. And a callee that writes a view of `( rc_get ( vec_at hs 0 ) )` into an `inout` parameter leaves the caller's view unmarked. Until the fix ships, do not change an Rc's payload through another handle while a loop walks it, and take a view of a payload after the call that changes it.
- **agora #776: a function that consumes its `inout` parameter on some paths only.** `@ g inout ( Vec S ) p i c → i { ? == c 1 { ^ ( eat p ) } {} ^ 0 }` (or `( eat ? == c 1 p ( mkv 3 ) )`): the function's summary says it consumes `p`, so its caller drops nothing, and on the path that does not hand `p` over the caller's value leaks. Until the fix ships, hand an `inout` parameter to a `sink` on every path, or take it by value as a `sink` parameter.
- **agora #797: a closure body growing a field or element handle read out of a parameter, a capture or its own parameter; a dyn call lending its argument's field.** A closure that grows a captured local read out of the function's parameter (`: String nm . a name`, a `vec_at` element), or that binds such a handle off its own parameter and grows it, and a `dyn` method returning its argument's field whose result is grown, are in no irealloc summary: the caller's view of that field or element dangles (heap-use-after-free). Until the fix ships, grow such fields in a named function rather than a closure, and take the caller's view after the call.

## Traits

| Limitation | Workaround |
|---|---|
| Bare-name method calls are **statically** dispatched — resolved to `method__<mangled-first-arg-type>` at monomorphisation, with no per-call vtable. Dynamic dispatch **is** supported but must be opted into via the `%Trait` object type + `( dyn Trait value )` construction: a `%dyn.<Trait> = { i8*, i8* }` box-plus-vtable fat pointer (spec §4.9). A trait must be **object-safe** to be used as `%Trait` (see `compiler/tests/should_fail_dyn_not_object_safe.nu`) | Keep the concrete type at the call site for static hot paths; for a heterogeneous collection, box values as `%Trait` with `( dyn Trait v )`, or use an enum of the variants and match |
| Associated types have **no projection**: an associated type cannot be named as `A::Elem` at a generic call site — it is usable only inside the declaring trait's own method bodies/signatures | Make the element an explicit type parameter of the function (`[A E]`) when a caller needs to name it |
| An associated-type binding (`type Elem Concrete`) must be a **single simple type name** (IDENT / type keyword); compound types (`* T`, `Vec T`, `?T`) are not accepted — the same restriction trait-default substitution carries | Bind to a named struct/alias type that wraps the compound type |
| Two type aliases that share an LLVM lowering (`i`/`i64`, `u`/`u8`, `f`/`f64`) cannot both implement the same trait method — they collide on one dispatch key and are reported as a duplicate impl | Pick one spelling per impl; the alias is the same runtime type |

## Concurrency / thread safety

Safe code is held to the ownership rules, data races included
([`MEMORY.md` §6.2](MEMORY.md)). What is trusted rather than checked —
marker assertions — is listed in
[`MEMORY.md` §3, §6.4, and §6.5](MEMORY.md); read those before relying on a
thread-safety expectation the rules do not state.

| Limitation | Workaround |
|---|---|
| `Send` / `Sync` are **derived from a type's structure, not proved**. The compiler knows four built-in cases — `Rc` (non-atomic refcount), `Cell` (raw unsynchronised byte buffer), a library handle (Sync only where asserted) and a trait object (Send only when its trait declares `: Send`) — and propagates them through struct fields, enum payloads, generic arguments, aggregates and closure captures. It knows nothing about an FFI handle: no C pointer is a leaf, however it is spelled — `*u` (as the sqlite declarations take a `sqlite3*`), `s` (as the `raw` stdio pass-throughs `file_raw` / `file_from_raw` carry a `FILE*`) or an integer — so a struct holding a `sqlite3*` or a `FILE*` derives as Send and crosses without a word. Binding a C library takes `unsafe` functions, and marking its handle types is part of what their author vouches for | Mark the type: `% NotSend Db { }` (or `% NotSync`) from `stdlib/core/marker.nu`. It propagates exactly like a built-in leaf — a struct holding it, a `( Vec Db )`, a closure capturing one are all rejected at the boundary. `stdlib/ext/sqlite` marks its own `Database` and `Statement` this way, so that one is handled; every other binding that wraps a C handle still has to say so itself |
| The derivation is also **conservative in the other direction**: a type that is thread-safe by construction but structurally suspect is rejected — one that holds a `Cell` but synchronises access to it itself | Assert it: `unsafe % Send T { }` / `unsafe % Sync T { }` (outside the standard library the `unsafe` prefix is required, [spec §3.3d](spec.md)). An explicit marker stops the walk at that type — nothing inside is examined, because you have taken responsibility for it. This is NURL's spelling of Rust's `unsafe impl`, and a negative marker outranks a positive one on the same type |
| `Send` answers "may this value **move** to another thread", never "is this program race-free". `( Vec i )` and `s` are Send **and** Sync — correctly, because sharing one read-only is ordinary code — so two threads *mutating* one is not caught by this check | It is caught by the move rule: a thread closure moves its captures, so only share handles (`Channel`, `Mutex`, `Arc`, `Locked`, `RwLocked`, `Atomic`, `PFile`) are used on both sides ([`MEMORY.md` §6.5](MEMORY.md)); a mutation through a shared `Arc` is the next row |
| Changing the **contents** of an `Arc` is rejected in safe code — on every thread, the one that made it included, and whatever lock is held. `Arc` makes the refcount atomic, not the payload: every clone reads it without a lock, and `arc_get` over a `Vec`/`String` hands back a handle aliasing the one buffer. A call that hands an `arc_get` result (or a field of one) to anything that changes it — a container mutator, a `String`'s or a map's, a helper, at any depth — is a compile error, and `arc_set` is for `unsafe` code only | Build the value first and `arc_new` it whole; put state threads share and change in a `Locked [T]` (`stdlib/std/thread.nu`: `locked_with` / `locked_set` hold its own lock, so the lock that guards the data is the one its type names), in an `RwLocked [T]` when many threads read it at once (`stdlib/std/rwlock.nu`: a read guard lends a frozen view), or in an `Atomic` for a single word; keep state one thread changes in an `Rc`; or give each thread its own copy and merge after `thread_join` |
| `thread_spawn` / `spawn` take a `( @ v )` closure; the worker runs on its own copy of the captured environment (a closure written in the call is handed over instead of copied), dropped when the body returns ([`docs/MEMORY.md` §7.5](MEMORY.md)). Send covers what the copy *reaches*. The closure moves its owned captures and takes its own share of a `Channel` / `Mutex` / `Arc` / `Locked` (`docs/MEMORY.md` §6.2); a `: ~` by-reference capture may not reach it (§2.3), and a raw `*T` exists only in `unsafe` code | Move shared state to a heap-backed, thread-safe handle before spawning: a `Locked` or a `Channel` for state that changes, an `Arc` for a value nobody changes |
| Module globals in safe code: a mutable scalar global (an integer, bool, float or `s`) is read and written atomically, but a mutable global of a struct or an option is reachable only from `unsafe` code (no atomic covers it), a mutable `s` global holds literals only (safe code may not hand it a string to own: the next assignment would free it under a reader on another thread), and a global set at start holds only a type that synchronises itself — the standard library's `Locked`, `Arc`, `Channel`, `Mutex`, `Cond` or `Semaphore`, never a bare `( Vec T )` — whose contents a thread may share: a `Locked`'s or a `Channel`'s value Send, an `Arc`'s payload Sync, so no `( Locked ( Rc T ) )` (h263, h272, h273, agora #639) | Keep state that changes at run time in a `( Locked T )` global set at start (`: ( Locked T ) g ( make )`, docs/MEMORY.md Module globals); a value nobody changes in an `Arc` |

## Functions and calls

| Limitation | Workaround |
|---|---|
| Calls require explicit parens — `( f a b )` is the only call form; a bare identifier is always a name lookup, never a call | Wrap every callsite: `( puts s )` |
| Struct parameters are passed by **value** by default (C/Go/Zig semantics) — `= . p field val` inside the callee writes a local copy; the caller's struct is unchanged | Mark the parameter `inout` (`@ bump inout Counter c → v`) — an exclusive mutable borrow, the callee mutates the caller's binding in place (see [`docs/MEMORY.md`](MEMORY.md)). Or return the modified struct (`= c ( inc_returning c )`); or use a `*T` parameter inside an `unsafe` function; or wrap state in a single-handle struct (`{ ( Vec i ) slots }`) |
| A closure hands its result to its caller as the caller's own, so it cannot hand back a value it does not own that cannot be copied (a `% Drop` value with no clone — its parameter, its capture, a field of either, what a lending call lent), nor a view (a Slice, a struct of views) of what it captured; a raw string it lent comes back a copy (docs/MEMORY.md, h219/h220) | Hand back a value the body makes, or take what the view points into as an argument — a view of an argument is followed at the call. A plain function may lend its parameter or a field of one |
| A function cannot hand back a field that cannot be copied out of a struct it drops, a module global or a capture (h221) | Keep the value in a binding of its own and hand that back, or hand back the whole struct |
| A closure that moves out a capture it cannot copy (a `% Drop` value with no clone) runs at most once — one that may leave its frame and is run again after the move, or after a copy of it (a thread's) took the value, stops with a panic (h222, h236, h239, h244) | Pass the value as an argument, or move it in a closure that is run once |
| A closure that may leave its frame (handed back, to a thread, a fiber or a callee, or bound to a name used other than as a callee) takes a capture it cannot copy from the frame when it is made, even one it only reads: the frame cannot use the value after that (h240–h243) | Make the closure after the frame's last use of the value, or call the closure only by name so it stays in the frame |
| A function cannot hand back a view of a `sink` parameter it drops (h225) | Take the parameter by lend (no `sink`), or hand back the value itself |
| A value that cannot be copied which a call only lends (`vec_at` of a `( Vec Res )`) cannot be stored, pushed or handed to a `sink`; nor can such a field be moved out of a struct that still drops it (h229, h230) | Take it out of its owner first (`vec_pop`, `vec_remove`, replacing the field), or lend it |
| A value that cannot be copied which a call lends out of one of the function's own locals (`^ ( getr h )` with `h` local, or a binding of it — `: D d \ ( getr h )`) cannot be handed back, assigned to an `inout` parameter, stored, pushed or put in a literal: the local releases it on the way out (agora #187, #196, #200; h918–h925) | Take it out of its owner (`vec_remove`, `vec_pop`, a function that hands it over) and hand that back, or hand back the owner itself |
| A generic that copies its `T` (`box_clone`, anything built on `mem_dup`) cannot be instantiated with a value that cannot be copied; the error points at the copy inside the generic, not at the call (h235) | Move the value instead, or give the type a clone |
| A match arm cannot hand an enum's payload that cannot be copied to a `sink` or an owner: the enum keeps it (h231) | Match on the enum to read the payload; to take it out, give the enum a variant constructor that hands it back from a function that takes the enum as `sink` |
| A match cannot hand a payload it only borrows that cannot be copied — of an option a struct field keeps — to the binding it initialises (h227) | Read the payload in the arm, or take the option out of the struct first |
| A closure whose body changes a capture (grows, clears or replaces it) cannot be handed to a call, or called, beside another argument that reaches that capture — the binding, a borrow or view of it, or another closure that captured it — and cannot itself hold a view of that capture (h274–h280) | Hand the callee what it needs as a parameter instead of capturing it, as `ws_serve_messages_deflate_with_context` gives its handler the deflate context ([`MEMORY.md` §2.11](MEMORY.md)) |
| A closure captures by pointer into its caller's frame a `: ~` binding it assigns or hands to an `inout` parameter, and a `: ~` multi-field struct (a callback counts into its caller's binding; `recover \ → v { = out ( f ) }` hands a result out); such a closure cannot leave the frame — returned, stored in a container, or handed to a thread, a fiber (`spawn*`) or `signal_install` ([`docs/MEMORY.md` §2.3](MEMORY.md)). Every other capture is copied when the closure is made | Keep state a closure that outlives its frame changes in a heap-backed handle: an `Atomic`, a `Locked`, an `Rc` |
| A parameter may not be named `r` followed only by digits (`r0`, `r12`, …) — a by-value parameter keeps its source name as its LLVM SSA register, and nurlc's temporaries are `%r0`, `%r1`, … in the same namespace | Rename it (`r0` → `r_0`, or something that says what it holds). Locals are unaffected — the code generator names those |
| A `sink` parameter owns and drops what it is given — a `String`, `Vec`, owning struct, handle enum, library handle, `Drop` value or a raw `s` (docs/MEMORY.md §1, §7.6). An **owned slice**, or a struct whose literal gave it one, is still **rejected at the call site**: its auto-drop obligation is not transferred | Pass an owned slice as an ordinary parameter and let the caller's scope drop it, or use a `Vec` |

## Ownership

| Limitation | Workaround |
|---|---|
| Freeing a field of a match payload (`?? o { T t → ( string_free . t name ) }`) hands the rest of the payload to the arm: it is dropped at the arm's end, and `o` must not be read after that match | Take the payload whole (`: Tagged x t`), or free the field after the last use of `o` |
| Storing a *borrowed* `String` / `Vec` into an owner (a struct literal, a field of a value, an element via `vec_push`) stores a **copy**; mutations through the new owner are not seen through the old binding | Store the owned value (move it in), or keep the shared buffer behind a pointer-reached struct, whose fields are stored as is |
| An element borrowed out of a temporary container (`( vec_get [T] ( mk ) 0 )`) is copied before the temporary is dropped; when `T` cannot be copied (a `% Drop` struct with no clone) that is an error, since nothing would own the temporary | Bind the container to a name first (`: ( Vec T ) v ( mk )`): it lives to the end of its scope, and the element borrows from it |

## Imports

| Limitation | Workaround |
|---|---|
| `import_decl` is a static inline-include (like `#include`) — the imported file is compiled into the same LLVM module | Avoid importing files that define `main`; avoid circular imports |
| Import alias (`` $ `path` alias ``) rewrites top-level `@`-functions, struct/enum types (generic structs included), enum variants, and global `:` constants to `alias__name`. FFI decls (`& "lib" @ name`) and trait/impl methods are intentionally NOT renamed — FFI symbols resolve at the linker by literal C-ABI name, and trait methods are mangled by the impl-target type | Use `pub` to scope FFI declarations to the importing file if collision is a risk |
| `__` in a type's name is the compiler's separator (`( Arc Bag )` is `Arc__Bag`; `geo::Point` is `geo__Point`): a struct, enum or trait declared with `__` past its leading underscores, or with a name ending in `_`, is refused, and so is an import alias that holds `__`, ends in `_`, or is the name of a type the program declares | Name types with single underscores or none, ending in a letter or a digit (`Arc_Bag`, `ArcBag`); give the import a lower-case module alias (`geo`, `my_geo`) |
| `pub` visibility covers `@`-functions, struct/enum types, enum variants (inheriting their enum's flag), and global `:` constants. Files with no `pub` decl stay in legacy mode (everything public, backwards-compat). FFI and trait/impl decls accept `pub` forward-compat but do not enforce | Mark each cross-file API entry with `pub`; the diagnostic `private X 'Y' is not visible across files` points at the leaked-private use site |
| `$`-import dedup keys on the `realpath(3)`-canonical file, so the same file reached through different symlink chains compiles exactly once; only when `realpath` itself fails (exotic filesystems) does dedup fall back to the normalised path string | None needed in practice; prefer the project-root-relative form (`stdlib/foo.nu`) for readability |

## Grammar

| Limitation | Workaround |
|---|---|
| Import is inline-include only: no namespaces. Alias rewriting covers `@`-functions, struct/enum types (generic structs included), enum variants, and global `:` constants; FFI decls, trait/impl methods and struct field names are deliberately not renamed. A module is compiled once, under its first import's spelling: a later alias of it reads as that spelling, but a plain import after an aliased one is refused | Put a plain import of a module before any file that aliases it (or alias it there too); prefix FFI names manually when collisions matter |
| **Every operator has fixed arity** (prefix notation has no closing token — a **locked 1.0 design decision**, see [`docs/spec.md` §6](spec.md); not a deferred gap). `&` / `\|` / `^^` / `+` / `-` / `*` / `/` / `==` / `!=` / `<` / `>` / `<=` / `>=` / `<<` / `>>` are all **binary** (`OP A B`); `?` ternary is `? cond then else`; `^` / `!` / `~` are unary. A missing or extra operand silently consumes the next token, so the diagnostic can land on the following line (when the swallowed line uses the binding being initialised, nurlc names the cause instead: "the initialiser of 'b' is one operand short and swallowed the statement on line N") | Count operands left-to-right when "unexpected token" fires on a line that looks fine. For n-ary `&`/`\|` chains write `& A & B C` or `& & & A B C D` (n−1 operators for n atoms), or factor a predicate helper (`is_alpha`-style); the compiler rejects the common `? & A B C D { … } { … }` shape as a hard error by default (`nurlc --no-strict-arity` demotes it to a warning; this repo additionally runs `tools/check_strict_arity.sh` over its whole tree in CI) |
| **`^` is the `return` keyword, not XOR** — but `^^` (two adjacent carets) **is** the native XOR operator. `^ a b` parses as `return (a b …)` | Use `^^` for XOR. The lexer pairs `^^` only when the carets are adjacent, so a stray space (`^ ^`) still means two returns |
| **Nesting depth is limited** (Agora #207). nurlc stops with a diagnostic past 1000 levels of expressions, blocks and types inside one another, instead of running out of stack. A nested `?` statement with its block counts as about three levels, a call or an operator as one or two. The playground fixes the limit at 200 | Split deep code into functions or bind intermediate values. Generated code that needs more passes `--max-nesting=N` or sets `NURL_MAX_NESTING=N` (0 turns the limit off); nesting much deeper than the default can also need a larger stack (`ulimit -s`) |
