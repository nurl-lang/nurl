Sources

A source is a public service the server fetches on a schedule and feeds into a model — a weather office's WFS, for instance. Each run asks only for the observations it has not seen yet, so nothing lands twice; Backfill reaches further into the past than the first run did.

Add a source

Point it at a WFS 2.0 endpoint, pick a stored query, fill in where, preview what the last hours would give, tick the columns that should be features, and say which model to feed and how often. The ::simple queries answer one value per row, which is what pivots into a data point.
