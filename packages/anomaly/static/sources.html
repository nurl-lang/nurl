Sources

A source is a public service the server fetches on a schedule and feeds into a model — a weather office's WFS, for instance. Each run asks only for the observations it has not seen yet, so nothing lands twice; Backfill reaches further into the past than the first run did.

Add a source

Point it at a WFS 2.0 endpoint, pick a stored query or a feature type, fill in where, preview what it gives, tap the columns that should be features — as numbers, or as categories so a place or a station is an identity the anomaly is judged against — and say which model to feed and how often. A weather service's ::simple stored queries answer a value per row; a GeoServer's feature types answer a feature per row with its properties, and each fetch is a snapshot unless a property is a date.

1Service

The URL is requested as given, query string and all, with the headers below — an API key, a token, a Digitraffic-User. Header values are stored on the server and shown masked afterwards. The answer's JSON is read at path: an array gives one record per element, an object one record; nested objects are flattened (current_temperature_2m), arrays inside a record are left out.
