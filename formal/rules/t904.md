| A closure's capture taken by pointer is given a call's lend of another capture of the closure (`= o ( id other )`, `= o { ( id other ) }`, or a binding of such a lend by name, `: x ( id other )  = o x`). It now gets its own copy, where the call (or the binding) did not hand its value over, and a type with no copy is refused. Before, it was left a lend of the other capture "as the same line outside the closure would", but the caller's frame, where it runs the closure, never learned that its binding borrows that one. Replacing or consuming the other capture after the call, then reading the first, read freed memory (main 05206020; AGORA-882's seven probes and AGORA-904's). The rule is the one AGORA-872 applies to a lend of a closure local or parameter (__cc_dying_lend; __cc_capture_lend for the by-name case), and the one the engine and tools/ncore already apply (a lend is copied into the place that owns it, §7.6) | §7.4, §7.6 | no: the calculus stores into a capture only what it owns (a by-pointer capture is an `inout`-like place, `capDeps`); nurlc now keeps to that | none to the proof |
