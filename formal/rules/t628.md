| A value block passed as an argument, ending in a call, is that call's result for what the argument leaves the caller to release after the call (`mem_arg_temps` is asked with the block's effective token). Asked as a block, a result the tail call made was released by nobody. What the block bound lives to the end of the enclosing scope, so a lend out of it is good for the call. The argument is then a temporary of the statement where the tail call may make its result, so a view of it kept past the call is refused as for the unblocked call (`: s d ( string_data { ( pick x y ) } )`, as `( string_data ( pick x y ) )` is) (agora #628 item 1) | §7.1 | no: releases, and rejects more only. A kept view of a block argument whose tail call may hand back a value of its own was accepted; where it did, the value leaked so that the view stayed good | none to the proof: a call's temporary argument is dropped after the call (A2's `letv` of the argument around the call), and a view of it does not outlive it |
