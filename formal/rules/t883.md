| A `??` arm's payload of a program enum that a binding holds is lent to the arm and read in place, and the arm binds a copy of it (MEMORY.md, h231). A field of that copy given a value that owns memory is refused, as for the other borrowed copies (a by-value parameter, a `~` element, a closure's by-value capture: agora #488, #643). The store lands in the copy, the enum keeps its old value, and nothing releases the new one. A field that owns nothing given a value there is warned about as lost. The refusal names the fix: give the enum a new value with the field changed, or `mem_dup` an owned copy. ncore: the same, `borrowed_copy` of an `enum_lent` payload.
