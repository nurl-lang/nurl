| The exclusive-call check counts a callee that may move the buffer of an element of argument j (g_fn_ireallocs: `( vec_push ( vec_at vv 0 ) … )` through a borrowed `vv`). Beside it, another argument that views an element of j's storage (`^vv`, __bck_elem_view_conflict) is refused: inside the call the two are unrelated names, and the view dangles once the element grows. A view of j's own buffer, or of an unrelated owner, stays accepted. This is nurlc's side of the (B') design's CallT premise, `ThruFn P f → ∀ r ∈ callR Γ args, r ∉ argRoots Γ args` (agora #3964), with argRoots taken as the arguments' own path roots.
