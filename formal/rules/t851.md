| A field store through a nested path (`= . . p inner name v`) whose root is a borrowed copy (a `~` loop element, a by-value parameter, a by-value capture) gets the borrowed-copy question that `= . p f v` already gets (`__fs_borrowed_copy_kind` of the path's root). An owning value is refused, because the store lands in the copy and nothing would release it. A value that owns nothing is lost, and that is warned. A closure with an environment stored into a field of such a copy counts as owning, since `mem_clo_into_store` makes the stored environment the field's (`__fs_clo_owns`: a literal that captured, or any non-literal closure value); one capturing nothing is warned as lost. Before, the nested path had no object name, so the question was never asked, and a closure was only warned as a lost write.
