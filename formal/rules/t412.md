| `= o ( f … )` for an option or result owner `o` (a payload that owns something) — a local with a drop slot, or an `inout` parameter, the caller's binding — where f may lend `o` itself AND another argument is refused. "Another" is counted by the callee's lent positions: a bare name other than `o`, or an argument that is no bare name but may lend what it reads (a call that lends or is not compiled yet, a field, a `?`/`??` join — `( pick o ( id other ) k )`, `( pick o . s y k )`). A fresh value or a literal the call is handed is copied where it is lent, and is not another. Such a call's per-call ownership answer is "lent" on both runs, so neither keeping o's old value (#342's gate: o kept its old flag over the OTHER argument's value, which both then dropped) nor dropping it (the run that hands back o's own value freed it under o) is right on both. #342's gate stays for calls that may lend nothing but `o` (`( id o )`); a copy of the result (`mem_dup`) or a new name is accepted (agora #412, claude-formal's HOLD on github#1517).
