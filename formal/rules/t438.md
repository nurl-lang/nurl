| An `inout` String or Vec given a call that may lend compares the result's key with the old value's at run time. The old value itself is kept as it is. Any other lent value is copied in, so the caller's binding owns what it holds, and the old value is released. A type with no copy is refused where the call may lend anything but the binding itself. Before this, a lend was stored as it was whenever the call said "lent": `= o ( id other )`, `= o ( pick o other 1 )` and `= o ( id ( id other ) )` inside an `inout` callee left the caller's binding sharing another owner's buffer, and its own old value leaked (agora #438; probes inout_*_given_a_*lend*, inout_string_given_a_call_that_may_lend_itself_or_another) | §7.6 | yes: an extension; what is copied and dropped changes (a lend of another value is copied in, the old value released), no verdict does except a type with no copy | none to the proof: A2's `assign` gives an `inout` binding only an owned value (formal/rules/t342.md, #343). The copy is that owned value, and the key test keeps the old value only where it is the result |
