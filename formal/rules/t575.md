| A value block's names end at its `}`. A block in value position that is no scope of its own (`: String e { : String s … }`, `= x { … }`, `( f { … } )`) binds in the enclosing scope, and its bindings' storage and drops stay there, since the block's value may view them; their names stayed too, in place of an outer binding of the same name or where there was none, while the walk ends a block's names at its `endblock` row — so a read after the block was judged as one binding and compiled as another. Each binding such a block makes now leaves a mark in its scope (`<name>__vbgone`), and a name spelled while the mark is newer than the binding it reaches is refused: in an operand, a call's callee, an assignment's or a field store's target, a closure's capture. A `:` of the name made later takes the mark away; a payload, a loop variable or a binding of an inner scope is newer than it. The bindings themselves are untouched, so every program still accepted compiles to what it did (agora #575) | §1 | no: rejects more only.
