| A function's summaries see through a join or a value block of a parameter. A value block or a join whose value is one binding or field path (`: j { v }`, `{ . h a }`, `? c v v`) derives from that name, as the bare spelling does (`__pderiv_note`), so a drop through the binding is a drop of the parameter in the function's drop summary. A join or a value block handed to a callee that lends it back lends each binding or field path it hands on (the walk's kind-32 row adds them to the line's pending lends, `bck_plend_add`). Before this a callee clearing `{ v }` ended none of its caller's borrows, and `( idv ? c . h a . h b )` gave a result tied to nothing (agora #556).
