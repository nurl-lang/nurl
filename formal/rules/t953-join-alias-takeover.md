| A binding given by name a `:` binding of a join whose arms each lend a different owner of a deeper scope (`: e ? c ( id a ) ( id b )  = o e`, `__jalias`) takes over, on each run, only the owner whose value it now holds. That is decided by the value's key (mem_ud_ident_key), and at most one owner is taken: two shares of one Rc keep a release each. A null key tells no owner apart, so every owner is taken over as before, a leak at worst and never a release under a holder. An owner is keyed by its own type only where that key names the value it would have handed the binding: the same type, or an option or a result with a side of that type (keyed by its active side). Any other owner, such as a struct that lent one of its fields, is taken over as before, because its key (its first field) does not name the field the binding holds. The other owner keeps its value and releases it. The mark follows the value through mem_udrop_link_alias (`: e2 e`). The core IR marks the takeover CORE_VF_CPCOPY.
