**agora #693: `% NotSync ( W i )` is not asked by the frozen-Arc rule.** With `unsafe % Sync W { }` on a generic type and `% NotSync ( W i ) { }` taking the promise back for one instance, a call handing that instance out of an Arc's payload to a function that changes it is excused as "a handle that synchronises itself" (the excuse looks the mark up by the generic name only), where the Send/Sync walk and the Sync-closure rule honour the opt-out; threads sharing the Arc then grow one Vec together (double free). It takes the program's own `unsafe` marker to reach: an `unsafe % Sync` on the generic type and on an enclosing type. Until the fix ships, do not rely on a `% NotSync` instance to keep a generically promised type out of shared state: keep it behind a Mutex or a Locked.
