**agora #493: a `~ x t` loop going on after `t` grew through another name.** With `: ~ ( Vec String ) cur t`, a `( vec_push [String] cur … )` inside `~ x t { … }` (or growth through a helper given `t`'s owner, or a closure that grows it) moves `t`'s buffer, and the loop reads its next element from the old one (heap-use-after-free). The same growth by `t`'s own name is refused. Until the fix ships, do not grow a container through any name inside a loop over it unless a `break` follows the growth; use an index loop (`~ < k ( vec_len … )` with `( vec_at t k )`) instead.
