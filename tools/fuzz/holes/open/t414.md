**agora #414: a view stored through a borrow that is not followed to its
owner.** A container bound from a join of names (`: ( Vec s ) w ? == c 1
{ vs } { vs2 }`), a `~ e vv` loop's element, `( id ( vec_at … vv 0 ) )`,
`( opt_unwrap ( vec_get … vv 0 ) )` or a program enum's payload, then
`( vec_push [s] w ( string_data loc ) )`: the owner never learns it holds
the view, and read after `loc` ends it reads freed memory. Until the fix
ships, push a view only into a container named by its owner, and keep
the view's source alive as long as that owner.
