cleared.** `( k a t )` gives `a` a view of `t`, then `? > n 5 { = a @ W {
`lit` } } {}`: the walk keeps one dependency table per function, not per
path, so the reassignment on one arm clears `a`'s dependency on `t` for
the other path too, and `a` read after `t` ends reads freed memory. The
same holds after a `break` or in a sibling `??` arm. Until the fix ships,
