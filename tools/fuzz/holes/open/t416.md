**agora #416: a `??` used as a value whose brace-less arm is a binding
that holds a view.** `= a ?? o { T m → @ W { `lit` } F → a }`, with `a`
viewing a String that ends before `a` is read (or `F → b`, `b` such a
binding, pushed or assigned): the join loses the arm's source, and the
read is of freed memory. A braced `{ a }` arm is refused. Until the fix
ships, brace such an arm or match in statement form.
