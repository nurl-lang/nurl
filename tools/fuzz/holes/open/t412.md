**agora #412: an option or result owner given a call's result that may
be either its own value or another owner's.** `= o ( pick o other 1 )`,
with `pick` handing back one of its two arguments: on the run that hands
back `other`'s value, `o` keeps its old ownership flag, so `o` and `other`
both release that value and the second release reads freed memory (`o`'s
old value is never released). Until the fix ships, don't give an option
or result binding the result of a call that is handed both that binding
and another owner; bind the result to a new name instead.
