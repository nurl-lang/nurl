**agora #918: a `% Drop` that changes a shared Rc payload, run at a function's exit under the view it hands back, or from a returned closure's environment.** A function that hands back a view of a parameter's Rc payload (`^ ( slice_from_vec ( rc_get x ) )`) while a local holding a share of the same Rc (`: H h @ H { ( rc_clone x ) }`) is released at its exit, its destructor clearing the payload, hands the caller a dangling view. And a closure whose environment took such a value (`@ mkf sink H h → ( @ i ) { ^ \ → i { … } }`) runs the destructor when the closure is released, ending no view through another handle. Either way a later read is of freed memory (heap-use-after-free). Until the fix ships, take the view after the call returns, and release such a closure before taking views of the payload its value shares.
