**agora #833: a value block passed as a by-value argument, its tail a binding of its own (#663 item 3).** `^ ( idg [String] { : String t ( mk c ) t } )`: the call hands back `t`, which this frame still releases on the way out; the result is not copied, as `^ ( idg [String] t )`'s is, so the caller reads freed memory. Until the fix ships, bind the block's value with `:` and pass the binding.
