**agora #368: a copy (`mem_dup`) or a popped element (`vec_pop`) of a
value that holds views.** `( vec_push [Tok] outer ( mem_dup t ) )`, `t` a
`Tok { Word ( string_data line ) }`, or `= keep ( vec_pop [Tok] toks )`:
the copy, or the element taken out, carries no dependency on what its
views point into, so kept in an outer owner past that source it reads
freed memory. The same holds for a struct with a view beside an owned
field. Until the fix ships, keep copies and popped elements of
view-holding values inside the scope that owns their source.
