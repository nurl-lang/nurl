**agora #680: a sink call in a returned expression.** `: Col c ( vec_at [Col] cs 0 )` then `^ ( keep . c name )` (`keep` takes its String) - also `^ + 1 ( keep . c name )` and the call as a function's implicit last value - is accepted, although the same call bound first (`: i n ( keep . c name )`) is refused: the field is freed while the Vec still owns it (use-after-free, then a second free). Until the fix ships, bind such a call's result with `:` and return the binding, and hand a sink a copy of a borrowed field (`string_clone`).
