**agora #574: a value block's own local as its tail, given to a binding of an outer scope.** `= v { : ~ ( Vec i ) w ( vec_new [i] ) … w }` with `v` an `inout` parameter, or `= w2 { : ~ ( Vec i ) u … u }` in a loop body with `w2` outside it: the block's local is still dropped at its own scope's end, under the binding that now holds its value (heap-use-after-free). Until the fix ships, bind the new value outside the block (`: ~ ( Vec i ) u …` then `= v u`).
