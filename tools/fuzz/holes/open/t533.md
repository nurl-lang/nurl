**agora #533: a binding given a value out of a borrow bound in an inner block.** `: ~ ( Vec E ) w ( vec_new [E] )  { : E x ( vec_at [E] top 0 ) = w . x kids }  ( vec_clear [E] top )`: at the block's end `x`'s borrow is retired and `w`'s tie goes with it, instead of passing to what `x` borrows from, so `w` is read after `top`'s elements were freed. A String field (`= w . x name`), an element of an element, and a loop body as the block do the same; the spelling with no block is refused. Until the fix ships, bind `x` in the scope that reads `w`, or copy the field (`= w ( vec_clone [E] . x kids )`).
