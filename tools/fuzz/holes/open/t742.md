**agora #742: `= o ( f1 o )` through a forwarder declared above its callee.** With `@ f1 String p → String { ^ ( f0 p ) }` declared above `@ f0 String p → String { ^ p }`, `= o ( f1 o )` releases the old value of `o`, which is the new one (heap-use-after-free); declared top-down it keeps it. Until the fix ships, declare a function that hands back its parameter above the functions that forward it, or bind the result under another name.
