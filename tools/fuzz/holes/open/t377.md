**agora #377: a copy of a Vec of views made some other way than the
library's element copies.** A function of your own that calls
`vec_extend` or returns a `vec_clone` of its parameter, `vec_clone_with` /
`vec_map` / `vec_filter` with a closure that hands the element back,
`map_clone`, `slice_copy`, a clone of a clone, and the clone of a call's
lent result all give the copy none of the views it holds, so it can be
read after the Strings they point into are freed. `vec_extend`,
`vec_extend_range`, `vec_clone` and `slice_to_vec` called directly are
followed (#347). Until the fix ships, call those directly, or copy the
Strings themselves (a `( Vec String )` copies each element deep).
