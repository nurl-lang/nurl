**agora #311: a binding re-pointed on one path of a `?` keeps no borrow
source on the other.** `: ~ String e ( vec_at [String] vs 0 )` then `? c
{ = e ( string_from … ) } {}` then `( vec_clear [String] vs )`: on the
path that kept the borrow, a read of `e` reads freed memory, and nothing
refuses it. Swapping the two arms changes the verdict. Until the fix
ships, give a borrowing binding a new value on every path of a join or
on none, or end its source's use before the join.
