**agora #554: a `: ~` cursor assigned from itself.** `: ~ ( Vec S ) j . h a`, then `= j j`, `= j { j }` or `= j { : i t 1 j }`, then `( vec_clear [S] j )`: the self-assignment drops the cursor's borrow of `. h a`, so the clear ends no element borrow of it and a String read out of one reads freed memory (heap-use-after-free). Until the fix ships, do not assign a cursor its own value; there is nothing to re-point.
