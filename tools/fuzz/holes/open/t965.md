**agora #965: a closure's capture given by name a `:` join over two literal-built local options' lends.** `: ?String e ? == k 0 ( idq a ) ( idq b )  = cap e` inside a closure, `a` and `b` local options built by literals, hands `cap` a value that `a` or `b` releases when the closure returns, so reading `cap` afterwards is a heap-use-after-free. Until the fix ships, assign the join directly (`= cap ? == k 0 ( idq a ) ( idq b )`, which copies where it lends) instead of through a binding.
