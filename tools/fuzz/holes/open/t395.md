**agora #395: a store through a borrow that #292 does not follow to
its owner.** Inside a closure, through a borrow of a capture (`: ( Vec s
) w ( id vs )  ( vec_push [s] w ( string_data loc ) )` with `vs`
captured); with an unbound call as the container (`( vec_push [s] (
vec_at [( Vec s )] vv 0 ) … )`); or through an option payload cursor
(`?? ov { T w → ( vec_push [s] w … ) }`): the owner never learns it holds
the view, and read after the source ends it reads freed memory. Until the
fix ships, bind the container to a name outside closures before storing a
view into it, and keep the view's source alive as long as its owner.
