**agora #737: an argument written as a call over a Vec of shares.** `( ch ( slice_from_vec hs ) )`, with `hs` a `( Vec ( Rc ( Vec u ) ) )` holding `r` and `ch` replacing an element's payload, leaves a slice taken through `r2` (a clone of `r`) dangling (heap-use-after-free); the same call with the slice bound first is refused. Until the fix ships, bind such an argument before the call.
