**agora #556: a function's summaries miss a join or a value block of a parameter.** A callee that clears its parameter through `: j { v }` or `: j ? c v v` (or `{ . h a }` of a struct parameter), one that hands back `: j { . h a } ^ j`, and an identity function given a join or a block argument (`( idv ? c . h a . h b )`) tie nothing in the caller: its element borrows survive the clear, or the result is no borrow, and read freed memory (heap-use-after-free). Until the fix ships, use the parameter or the field by its own name in such a function (`( vec_clear [S] v )`, `^ . h a`), and pass a field or a name to a forwarding call.
