**agora #342: an option owner given back its own value through a
call.** With `: ~ ?String o ( make )` and a callee that hands its
argument back (`@ id ?String x → ?String { ^ x }`), `= o ( id o )` drops
`o`'s old value and then stores it again, so the next read of `o` is of
freed memory. The same with a `String` binding is right. Until the fix
ships, do not give an option binding the result of a call that is handed
that same binding.

The same happens with a Vec read out of the option on the way: `: ( Vec
Node ) w ( optkids_fwd o )  = o ( firstn_fwd w )`, with forwarders
defined below their caller, frees the old `o` that the new `o` lives in
(a struct's child handed back through two forwarders). Found by the #352
adversarial pass.
