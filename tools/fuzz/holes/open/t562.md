**agora #562: a value block whose tail is a block-local binding shadowing the assigned name.** `= v { : ~ ( Vec i ) v ( vec_new [i] ) … v }` (or the same with a String): the block's own `v` is handed out by name to the outer `v`, and the old value and the new one are confused, so one buffer is used after it is freed (heap-use-after-free). Until the fix ships, give the block's local a name of its own (`{ : ~ ( Vec i ) w … w }`).
