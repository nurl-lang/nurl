**agora #396: a view taken through a String field reader, kept past a
realloc of that field.** `: String f . t name` then `( vec_push [s] o (
string_data f ) )`, and later `( string_push_str . t name … )`: the view
is recorded as reaching `t` only through an element, whose buffer stays
put, but the field's own buffer is what the push moves, so reading `o`
afterwards reads freed memory. Until the fix ships, take views of a
String field only after its last change, or store a copy (`string_from`).
