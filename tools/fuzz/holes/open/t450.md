**agora #450: an owner given a part of its own value through a borrow
bound first.** `: Tr c ( vec_at [Tr] . t kids 0 )  = t ( tfwd c )`: c
is a lend out of t's Vec field, from a generic compiled after the
caller, and t is given what tfwd lends back of it. t's old value is
released with the element inside it, and reading t reads freed memory.
Until the fix ships, copy the part (`mem_dup`) before giving it to its
owner.
