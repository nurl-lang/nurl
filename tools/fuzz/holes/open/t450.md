**agora #450: an owner given a part of its own value, or a value that
shares part of it, while nurlc takes the result for another value.** `=
o ( first o )`, with `first` handing back an element of o's own Vec
field through a generic it calls; a program enum keyed on a number (`A 7
…`); or a `: ~` cursor copy of a struct whose first field was replaced:
o's old value is released with the part inside it, and reading o reads
freed memory. Until the fix ships, take the part out of the owner into a
new binding (or copy it, `mem_dup`) before giving it to the owner.
