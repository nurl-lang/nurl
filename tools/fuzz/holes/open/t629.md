**agora #629: a value block's tail binding consumed inside the block, beside an outer binding of its name.** `: String e { : String s … : i n ( eat s ) s }` with an outer `s` in scope: the tail's read is judged against the outer `s`, which nothing moved, so the consumed value is handed on (heap-use-after-free); without the outer `s` it is refused. The same resolution refuses a correct block whose tail is its own fresh binding after the OUTER one was moved. Until the fix ships, give a value block's bindings names of their own.
