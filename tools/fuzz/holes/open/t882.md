**agora #882: a closure gives a captured owner a lend of another capture.** `: ( @ v ) f \ → v { = o ( id other ) }  ( f )  = other ( mk … )  ( show o )`: after the call `o` borrows `other`, but the call site does not tie them, so replacing `other` is not refused and `o` then reads freed memory. The same when the other capture is replaced inside the body, or is a local of an enclosing closure that an inner closure lends. Until the fix ships, give the captured owner a copy (`mem_dup`) of the other capture's value inside the closure.
