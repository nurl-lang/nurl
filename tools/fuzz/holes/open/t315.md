**agora #315: a callee that changes what is inside its parameter's
elements.** `@ clear_first ( Vec ( Vec String ) ) p → v { ( vec_clear
[String] ( vec_at [( Vec String )] p 0 ) ) }`, or the same through a
local element borrow, a push that moves the element's buffer, or a field
of an element: the call ends none of the caller's borrows of that
element's contents or views of its buffer, so reading one after the call
reads freed memory. Until the fix ships, take such a borrow again after
the call instead of holding it across it.
