**agora #681: an enum payload matched in place out of an Arc.** `?? . ( arc_get [App] mine ) ev { Got p → { ( growp p k ) } … }` - a user enum field of an Arc's payload matched without binding it first - gives the arm a payload the frozen-Arc rule does not know is part of the Arc, so a callee (or `vec_push` itself) changes what every thread holding a clone reads: a data race, a double free when it grows a Vec. The option form is refused from github#1755 on, and the enum bound to a name first is refused. Until the fix ships, never change an arm's payload that came out of an Arc; keep changing state behind an Atomic, a Mutex or a Locked inside the Arc.
