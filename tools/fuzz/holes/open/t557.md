**agora #557: a borrow through one `??` and a change of the payload's field in another, the join-arm shape.** `: ( Vec String ) k ?? ev { A p → ? == c 1 . p a . p b  B q → . q a }`, with an element of `k` borrowed, then `?? ev { A p → { ( vec_clear [String] . p a ) } … }`: the join's arm is itself a ternary of payload fields, so its source expression is a list (`{…}`) and the join borrows nothing, and the second match's clear ends no borrow. A later read is of freed memory (heap-use-after-free). (The block-arm, plain, field-viewer and struct-element shapes are closed.) Until the fix ships, read the borrow before the second match.
