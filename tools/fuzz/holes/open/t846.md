**agora #846: views and closures of a value block's bindings, handed on after the block.** A value block's bindings live to the end of the enclosing scope, but the check ends them at the block's `}`, so nothing ties a view or closure of one to its real life: `: s d { : String t … : s x ( string_data t ) x }  ^ d`, a closure over a block local assigned outward (`: g { : f … = keep f f }`, then `= keep …`), and `= a { : h \ … h }` while a `;` defer that calls `a` is armed all use freed memory (heap-use-after-free; #638's rest, #839). The unblocked spellings are refused. Until the fix ships, bind such values with `:` in the enclosing scope instead of inside a value block.
