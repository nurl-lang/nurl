**agora #628: a value block ending in a call, where its result is not a `:` binding's or a local assignment's.** As a non-sink call argument (`( string_len { : String s … ( string_concat s s ) } )`), in a loop condition, assigned to an `inout` parameter, with a tail call that lends a temporary past a block local, or as a join of block locals handed to a `sink`, the result (or the binding not selected) is never released: a leak once per run of the statement. Until the fix ships, bind the block's value with `:` first.
