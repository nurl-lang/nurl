**agora #668: a `: ~` binding of a value block whose tail is the block's own binding, handed to a `sink`; a cursor `: ~ w u` given a new value and then handed to a `sink`; a tail named like the binding; a raw `s` tail handed back.** `: ~ String e { : String s … s }` then `( eat e )` reads freed memory; `: ~ w u`, `= w fresh`, `( eat w )` leaks `u`'s value; `: String s { : String s … s }` then a `sink`, and `: String e { : String s …  : String t { s }  t }` then a `sink`, read freed memory; `: s e { : s t … t }  ^ e` hands back a freed string. Until the fix ships, bind the block's value with an immutable `:` under a name of its own and one block deep (that spelling is right since 0.91.0), or build the value outside a block.
