**agora #588: a callee that moves its parameter's elements out in a `~` loop.** `@ wipe ( Vec String ) t → v { ~ x t { ( string_free x ) } }` (or a closure doing the same to a capture) ends no borrow at its caller: a view of an element taken before `( wipe t )` reads freed memory after it, where the same loop written inline is refused. Until the fix ships, do not keep a view or a borrow of a container's elements across a call that frees or takes them one by one.
