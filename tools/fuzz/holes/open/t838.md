**agora #838: a returned closure's effects are lost through a call that hands its argument back, or a closure literal's call.** `( pick ( mk xs ) other )`, a forwarder handing the closure on, the closure run in a loop, or `( \ … ( c ) … )`: running it after taking a view of what it changes leaves the view dangling (heap-use-after-free). (A closure stored in a struct, an Option or a Vec, and a join of closures handed to a helper, are refused on main.) Until the fix ships, run a closure a builder hands back from the binding it is bound to, or take the view after running it.
