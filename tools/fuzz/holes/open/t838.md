**agora #838: a returned closure's effects are lost through a call that hands its argument back, a struct, Option or Vec it is stored in, a helper handed a join of closures, or a closure literal's call.** `( pick ( mk xs ) other )`, `@ H { ( mk xs ) }` run from the field, `( run ? k c1 c2 )`: running it after taking a view of what it changes leaves the view dangling (heap-use-after-free). Until the fix ships, run a closure a builder hands back from the binding it is bound to, or take the view after running it.
