**agora #475 (rest): the keep rule for an option of an option handed back by a parameter of a callee defined above, and for a result of an Rc share.** A `!i String` and a `? ?String` given back by a callee below their caller are keyed now. Two shapes are still open:
- `= o ( f o k )` over a `? ?String`, with `f` defined above its caller, which returns its parameter `o` on one run and a fresh nested literal on another. The parameter path answers "owned" statically, so the old value is kept back on the run that hands over a fresh one (a leak).
- A `!( Rc String ) String` given back by a callee below, which returns its argument on one run and an `rc_clone` share of its payload on another. The share has the same key as the old value, so the new share is kept as if it were the old one and never released (a leak of one count).

Until the fix ships, bind the call's result to a new name (`: … r ( f o k )`) and move `r` in once `o` is no longer read.
