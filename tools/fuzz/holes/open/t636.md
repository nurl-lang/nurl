**agora #636: a binding made inside a `;` defer body takes over its name in the enclosing scope.** After `; { : i a … }`, a later `a` in the function means the defer body's binding, whose storage is written only when the defer runs: `: i a 5`, `; { : i a + n 7 … }`, `^ a` returns uninitialised stack memory, and with a closure or a String of that name the later use calls or reads through an uninitialised handle. Until the fix ships, give a defer body's bindings names nothing else in the function uses.
