**agora #840: a `: ~` cursor of a `??` payload stored inside its arm, or a struct cursor given a field before it is stored, gives the owner's value away unseen.** `?? o { T x → { : ~ cur x  : H q @ H { cur 0 } … } }` then reading `o` reads freed memory, and `: ~ H c h  = . c items ( vec_new )  @ W { c }` frees the new field twice. Until the fix ships, store the payload or the struct by its own name (`@ H { x 0 }`, `@ W { h }`), or a copy, `( mem_dup cur )`.
