**agora #482: a `~ x b` loop over a borrow of a container's element, the container changed in the body by its own name.** With `: ( Vec String ) b ( vec_at [( Vec String )] vv 0 )`, a `( vec_clear [( Vec String )] vv )` inside `~ x b { … }` frees the storage the loop walks, and x is read after it: the iterator rule (`iter_containers`) compares names and sees `b`, not the `vv` it borrows from. Until the fix ships, do not change the owner of a borrowed container inside a loop over it.
