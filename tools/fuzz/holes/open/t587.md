**agora #587: a field of a `~` loop's struct element moved out.** `~ x t { ( gone . x name ) }`, gone taking a `sink String`, or `~ r rs { ( string_free . r name ) }`, releases the field's value, and the container releases it again when it drops (heap-use-after-free, no view needed): only a whole element moved out empties its slot. Until the fix ships, do not hand a field of a loop element to a sink or release it; take the whole element out (`vec_remove`, `vec_pop`) and take it apart.
