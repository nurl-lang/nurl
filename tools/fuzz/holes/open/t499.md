**agora #499: a value block whose tail is an outer borrow.** `: ( Vec u ) j { e0 }` over `: ( Vec u ) e0 ( vec_at [( Vec u )] vv 0 )`, or `( vec_reserve [u] { e0 } 4096 )` inline, borrows nothing to the walk, so growing it leaves a slice of `e0` dangling (heap-use-after-free). `: j e0` and growing `e0` directly are refused. Until the fix ships, do not wrap a borrow in a value block (`{ e0 }`) to bind or pass it; use the name itself.
