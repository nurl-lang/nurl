**agora #716: a generic struct declared below every function that names its instance.** A generic struct's template is learned by the same pass over the file that makes its instances, so `( Wrap i )` written above `: Wrap [T] { ( Rc T ) r }` has no fields where it is written. When no field is read there and the instance is first made by a generic function further down, the program compiles — and the function above was checked against a type with no fields: its `thread_spawn` capture reaches no `Rc` (two threads clone and drop shares of one `Rc`: a use after free), and its binding of the instance is never released (a leak). Where a field is read the program is refused ("has no field"); with no later use it fails at clang ("Cannot allocate unsized type"). Until the fix ships, declare a generic struct above its first use.
