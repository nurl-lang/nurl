**agora #439: a view of a Vec's element taken through `( vec_at … )`,
then that element grown through a binding of it.** `: s v ( string_data (
vec_at [String] vs 0 ) )`, then `: String e ( vec_at [String] vs 0 )  (
string_push_str e … )` (or the same through a `vec_get` match payload):
the push moves the element's buffer but ends no view of it taken through
the direct `vec_at`, so reading `v` reads freed memory. Until the fix
ships, take the view through the same binding you grow, or after the last
change.
