**agora #844: a change made through a `( Slice T )` of a parameter's Vec that a struct literal holds.** `@ ext ( Vec String ) v → v { : SH h @ SH { ( slice_from_vec [String] v ) }  ( string_push_str ( slice_at [String] . h s 0 ) … ) }` is in no summary, so the caller's view into `v`'s element dangles after `( ext v )` (heap-use-after-free). A slice bound by name, a window, `slice_put`, `slice_get`, a helper or a dyn method handing the slice back are followed. Until the fix ships, keep the slice in a binding of its own, not in a struct literal.
