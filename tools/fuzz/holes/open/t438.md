**agora #438: an owner given back what a call may lend out of itself or
another owner, in shapes the hand-over gate does not reach.** A struct
given a lend of a part of itself (`= o ( first o )`, `first` lending `(
vec_at . x kids 0 )`), an `inout` String given a lend of another argument
(`= o ( id other )` in a callee), an enum keyed on an equal scalar first
payload, `o` reaching the call inside a wrapper (`( pick ( id o ) other k
)`), and a struct given back a `: ~` copy of itself that shares a field:
the old value is freed while the new one still lives in it, and a later
read is of freed memory. Until the fix ships, bind such a call's result to
a new name, or copy it first (`mem_dup`).
