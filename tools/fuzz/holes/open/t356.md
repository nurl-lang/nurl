**agora #356: a closure that stores into a field of a captured
single-field struct.** `: ~ P p …` with `: P { String name }` is
captured by value when the closure's only change is a field store
(`\ → v { = . p name ( string_from … ) }`), so the store lands in the
closure's copy: the binding keeps its old value, and the new one leaks. A
struct with two fields, or a whole assignment (`= p @ P { … }`), lands.
Until the fix ships, give the captured binding a new value whole, not by
a field store.
