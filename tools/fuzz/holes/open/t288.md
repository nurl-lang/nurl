**agora #288: a handle parameter not declared `sink`, handed back
inside a result literal from a `^ ?? r { … }`, leaks when the caller
passes a temporary.** `@ wrap H h → !H i { … ^ ?? r { T _ → @ !H i { T h }
… } }` called as `( wrap ( mk ) )`: the literal copies `h`, but the
caller's temporary is never dropped, so every call leaks the handle (and
what it holds). Until the fix ships, a function that hands a handle
parameter back, or drops it on failure, declares it `sink`.
