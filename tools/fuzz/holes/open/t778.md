**agora #778: an `inout` field target a callee hands to a `sink` and then panics.** `@ boom inout ( Vec S ) p → i { : i n ( eat p ) ( panic `boom` ) ^ n }` called as `( boom . h a )` under `recover`: the field is emptied only when the call returns, so the unwind drops `h` with `. h a` still holding what `eat` released (heap-use-after-free). Until the fix ships, do not panic after handing an `inout` parameter to a `sink`, or pass a whole local rather than a field.
