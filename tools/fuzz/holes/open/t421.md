**agora #421: a closure called with an element a call lends.** `( f ( vec_at [( Vec String )] outer 0 ) )`, with `f` a closure that clears its parameter, ends no borrow of that element's contents. A named callee there is refused. A function that calls its closure parameter on an element of its own parameter behaves the same. Both are a heap-use-after-free. Until the fix ships, bind the element first and pass the binding, or call a named function.
