**agora #627: a capturing closure bound in a value block and handed out as the block's value.** `: ( @ i i ) g { : ( @ i i ) f \ i x → i { … tag … } f }`, or `= f { … f }`: the block's binding and the binding that takes the block's value both own the closure's environment, and it is released twice (heap-use-after-free in the closure's drop). Until the fix ships, bind the closure outside a block, or write the closure literal as the block's tail.
