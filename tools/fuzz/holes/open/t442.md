**agora #442: a function or closure handing back an enum literal whose payload views its parameter or capture.** `@ mk String line → Tok { ^ @ Tok { Word ( string_data line ) } }`, or the closure `\ → Tok { ^ @ Tok { Word ( string_data line ) } }`, hands back a result with no source. Pushed into an outer Vec past the String, it is read after the String is freed: a heap-use-after-free. Until the fix ships, put a copy that owns its data in the payload (`Bad String` with string_from).
