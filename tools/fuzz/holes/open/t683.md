**agora #683: the Send/Sync walk and an option in a generic argument.** `( Vec ?( Rc i ) )` captured by a `thread_spawn` closure, or `( Arc ?( Rc i ) )` cloned to a thread, is accepted where `( Vec ( Rc i ) )` and a bare `?( Rc i )` are refused: the walk reads a generic's arguments off the mangled name, where an option is the slug `opt_Rc`, and never sees the `Rc`. Two threads then count one non-atomic reference count (heap-use-after-free / double free). Until the fix ships, keep what crosses a thread in an `Arc`, never an `Rc` inside an option inside a container.
