**agora #314: a container change whose container argument is a `?` or
`??` join.** `( vec_clear [S] ? c vs vt )` or `( vec_push [u] ? c bs bt
x )` ends nothing nurlc tracks: a borrow of an element of `vs`, or a
view of `bs`'s buffer, stays usable after the change, and reading it
reads freed memory. Bound first, `: ( Vec S ) j ? c vs vt  ( vec_clear
[S] j )`, the change is tracked. Until the fix ships, bind the join to a
name before changing the container through it.
