**agora #458: a local option captured by a closure that escapes its
function.** `: ?String x ( mk … )  ^ \ → i { ?? x { … } }`: the option
is released when the function returns, and calling the closure reads
freed memory. A captured String is taken into the closure. Until the fix
ships, capture an option's payload (a String) rather than the option, or
copy it into the closure (`mem_dup`).
