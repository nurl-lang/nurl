**agora #679: a view of a per-call-owned option's payload handed back.** A function that returns a fresh option on one path and a lending call (`vec_get`) on another answers per call; a caller that matches on its result and returns a view of the payload (`T j → { ^ ( string_data . j name ) }`) is accepted, because the walk takes the option for a borrow of the argument, yet on the fresh path the option is released at that return and the caller reads freed memory. The always-fresh form is refused and the always-lent form is correct. Until the fix ships, return an owning copy of such a payload's data, or make the callee answer the same way on every path.
