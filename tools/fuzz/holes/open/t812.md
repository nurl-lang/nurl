**agora #812: a view sent on a Channel.** `( chan_send [s] ch ( string_data m ) )` hands a view of `m` to whichever thread receives it; the "a view does not cross" check runs only where a thread is spawned, so the receiver reads freed memory once `m` is released (heap-use-after-free). The same holds for a closure holding a view sent on a `( Channel Job )`. Until the fix ships, send owned values (a `String`, not its `s`) or views of literals on a channel another thread reads.
