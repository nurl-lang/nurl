**agora #352: a call's lent result handed to a callee defined before it
that changes it only through a forwarder.** With `@ clear_fwd ( Vec
String ) e → v { ( clear_inner e ) }` compiled before its caller, `(
clear_fwd ( vec_at [( Vec String )] vv 0 ) )` records nothing, so a view
of that element's contents survives the call that clears it. The same
program with the functions defined after the call is refused, and
standard-library forwarders such as `string_push_str` are always in the
first position. Until the fix ships, bind the element first and pass the
binding, or define such functions after their callers.
