**agora #392: a view-holding value stored into an Rc's shared state.** A
callee doing `( rc_set [W] r @ W { ( string_data s ) } )` through one
share (`r2`, an `rc_clone` of `r`) ties nothing to `s`, so another share
read after `s` ends (`( rc_get [W] r )`) reads freed memory. Until the fix
ships, store only values that own their data (or view what outlives the
Rc) into an Rc's state.
