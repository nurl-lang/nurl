**agora #841: slices that nobody releases.** A slice returned through a closure call (`: [i ys ( mk n )`, mk a closure) leaks. So does a struct holding a slice reassigned under a `;` defer (`= q @ Q { [i | …] n }`), and an element or payload that owns a slice (a `( Vec Q )` with `Q { [i xs … }`). An enum with a slice payload (`: | E { A [i B i }`) does not compile to valid IR. A function with one return of a `: ~` slice that is given a fresh value on some paths (`: ~ [i r p  ? c { = r [i | 5 6] } {}  ^ r`) hands it back without publishing whether it is owned, so the fresh one leaks. Until the fix ships, keep such a slice in a binding of its own, which releases it, or use a `( Vec T )`.
