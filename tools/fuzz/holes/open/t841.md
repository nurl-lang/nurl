**agora #841: slices that nobody releases.** A slice returned through a closure call (`: [i ys ( mk n )`, mk a closure) leaks. So does a struct holding a slice reassigned under a `;` defer (`= q @ Q { [i | …] n }`), and an element or payload that owns a slice (a `( Vec Q )` with `Q { [i xs … }`). An enum with a slice payload (`: | E { A [i B i }`) does not compile to valid IR. Until the fix ships, keep such a slice in a binding of its own and release it by hand, or use a `( Vec T )`.
