**agora #409: a view of a match payload's field, kept past its arm, then
the payload changed in place through a second match.** `?? oh { T p → {
= w @ W { ( string_data . p name ) } } … }` keeps `w` viewing `oh`'s
payload past the arm (agora #336). A later `?? oh { T q → ( string_push_str
. q name … ) }`, a `vec_clear` of an `?( Vec String )` payload, or a
callee that changes the payload (through its own match on an `inout`
option, or handed `. q name`) moves or frees what `w` views, but ends
nothing on `oh`, so reading `w` afterwards reads freed memory. Until the
fix ships, read a payload's field view inside its arm, or copy it
(`string_from`) before keeping it.
