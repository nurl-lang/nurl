**agora #422: a function handing back a local holder that views its String parameter.** `@ mkh String s → ( Vec s ) { : ( Vec s ) h … ( vec_push [s] h ( string_data s ) ) ^ h }` returns a Vec viewing the caller's String, and the caller's result is not tied to that argument. The view may arrive directly or through a named, `dyn` or closure callee. Once the String ends, reading the result is a heap-use-after-free. Until the fix ships, keep the String alive as long as the result, or store owned copies (string_from).
