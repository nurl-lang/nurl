**agora #714: a type of the program's own named `Weak`.** The run-time check that stops a share handle from crossing to another thread while a second owner of the same state stays behind (§6.5) skips a type by the bare name `Weak` (and `Rc`), which it takes for the library's: `: Weak { PNCounter c i n }` — or a generic `: Weak [T] { T c i n }` — holding a share of a counter the spawner keeps is captured by a thread's closure with no check, and both threads change the one unsynchronised state (a double free). The same struct under any other name stops with the crossing panic. Until the fix ships, do not name a type of your own `Weak` or `Rc`.
