**agora #397: a callee that stores one parameter's view into another
through a borrow of it.** `@ push_into ( Vec s ) v s x → v { : ( Vec s )
w ( id v )  ( vec_push [s] w x ) }`: the caller does not learn that its
`v` now holds a view of what it passed as `x`, so reading `v` after that
source ends reads freed memory. The direct form (`( vec_push [s] v x )`)
is refused. Until the fix ships, store into the parameter by its own name.
