**agora #555: a join or a value block handed inline to a `sink` parameter.** `( eat { . h a } )`, `( eat ? c . h a . h b )` or `( eat { w } )` with `@ eat sink ( Vec S ) v`: the callee is given a value it does not own — the field or the binding is neither taken over nor copied — so it frees what `h` or `w` still holds, which is then freed again or read (double free, heap-use-after-free). Until the fix ships, hand the field or the binding to the sink by itself (`( eat . h a )`, `( eat w )`), choosing with a `?` statement around the call.
