**agora #868: a closure that keeps a by-value parameter it captured.**
`@ f ( Vec R ) log R p → i { : ( @ v ) run \ → v { ( vec_push [R] log p ) } ( run ) ^ 1 }`,
with R a `% Drop` type, is not taken to consume `p`: the caller still
releases its argument, and the element the Vec holds is freed memory
(heap-use-after-free). The same push written in f's own body is
summarised and runs clean. Until the fix ships, push a parameter in the
function's body rather than in a closure over it.
