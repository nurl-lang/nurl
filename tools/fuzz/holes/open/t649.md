**agora #649: a value block returned straight whose tail is a cursor of an element.** `^ { : ~ ( Vec String ) u … : String t ( vec_at [String] u 0 ) t }` hands the caller a String that views an element of `u`, which the function releases as it returns: the caller reads freed memory. The same for a field of an element bound in the block. Bound first and returned by name (`: String e { … t }`, `^ e`) the value is copied. Until the fix ships, bind a block's value before returning it.
