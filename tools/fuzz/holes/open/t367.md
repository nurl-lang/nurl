**agora #367: a `??` used as a value whose arm hands out a view
payload.** `: s got ?? t { Word w → w Num n → `` }` (or `^ ?? t { … }`),
with `t` holding `( string_data line )`: the join of the arms' values
names no source, so `got` is not seen to view `line`, and kept past it
(pushed into an outer Vec, or returned) it reads freed memory. It holds
for every enum, even one that owns nothing. The statement-arm form,
`?? t { Word w → { ^ w } … }`, is refused. Until the fix ships, match
in statement form and use the payload inside its arm.
