**agora #675: a generic struct of the program's own that holds an `Rc`, handed to a thread.** `: Wrap [T] { ( Rc T ) r }` — the Send and Sync rules do not read the fields of a generic struct's instance, so a `( Wrap i )` is captured by a thread's closure (or put in an `Arc`, a `Channel`, a `Locked`) while another share of the same `Rc` stays behind, and two threads count one reference count with no lock (heap-use-after-free, double free). The same struct written without a type parameter, `: Wrap { ( Rc i ) r }`, is refused. Until the fix ships, keep what several threads hold in an `Arc`, a `Locked`, an `Atomic` or a `Channel`, not in an `Rc` inside a generic struct.
