**agora #682: a payload view kept in a local Vec.** A `( Slice T )` over an Arc's payload pushed into a local `( Vec ( Slice T ) )` (or a Vec of structs holding one) and read back with `vec_get` / `vec_at` is no longer known to be a view of the payload, so `( slice_put w 0 x )` on it is accepted and changes what every thread holding a clone reads (a data race; a double free when the element owns memory). Bound directly, or inside an option or struct local, the same write is refused. Until the fix ships, never write through a view of an Arc's payload that went through a container; keep changing state behind an Atomic, a Mutex or a Locked inside the Arc.
