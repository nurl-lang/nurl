**agora #719: a closure run by several threads that changes a `% NotSync` instance inside what it captured.** The rule for a closure several threads run at once (one kept in an `Arc`) excuses a change made through a capture whose type synchronises itself, and asks that of the captured value's type alone: with `unsafe % Sync W { }`, `% NotSync ( W i ) { }` and `: App { ( W i ) wi ( W b ) wb }` asserted `unsafe % Sync`, a closure that captured an `App` and hands `. app wi` to a function that grows its plain `Vec` is kept in an `Arc` and run by eight threads (a double free). Handing the `( W i )` itself to the threads is refused, and so is the same change reached through an `Arc`'s payload. It takes the program's own `unsafe % Sync` on the holder. Until the fix ships, a type asserted `unsafe % Sync` must not hold an instance the program marked `% NotSync`.
