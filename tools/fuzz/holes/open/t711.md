**agora #711: a value nested deeper than the Send/Sync walk follows.** The derivation of `Send` and `Sync` (§6.5) follows a type through its fields, payloads and type arguments ten levels down and answers "nothing found" below that: `: L1 { ( Rc i ) r }`, `: L2 { L1 a }` … `: L11 { L10 a }` — an `Rc` eleven structs down — is captured by a `thread_spawn` closure, sent on a channel or put in an `Arc`, and both threads clone and drop shares of the one unsynchronised count (double free). At three levels the same program is refused. The frozen-`Arc` rule's walk has the same bound for a deep holder of an `Arc`. Until the fix ships, the walk's word is good ten levels down: a value that holds an `Rc`, a `Cell` or a share handle deeper than that must not be handed to another thread — use an `Arc` there.
