**agora #872: a closure local's lend given to an owner the closure captured.** `\ → v { : ?String other ( mk … )  = o ( id other ) }` (or a closure parameter, or `( spick o other k )` into a captured String) leaves `o` holding the closure's local, which is released when the closure returns: reading `o` after the call is a heap-use-after-free. Until the fix ships, give a captured owner only values that outlive the closure, or a copy (`string_clone`, `mem_dup`).
