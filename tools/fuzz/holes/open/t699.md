**agora #699: a function handing back a dyn method's result.** `@ viaobj %Src o ( Vec S ) v → S { ^ ( first o v ) }` — `first` a trait method one of whose impls hands back an element of `v` — is summarised as lending nothing, also with the result bound first (`: S r ( first o v )  ^ r`): the returned value is followed through the callee's summary, and a virtual call has no single callee. A caller that binds `( viaobj o va )`, clears `va` and reads the binding is accepted and reads freed memory; the same virtual call written in the caller is refused. Until the fix ships, call the trait method where its result is used, or have the forwarder hand back an owning copy (`^ ( mem_dup ( first o v ) )`).
