**agora #366: an owner's old value kept back where its hand-over has no
key, a leak.** A `: ~` owner given a value a call lends out of another
owner (`= o ( vec_get [Rec] rs 0 )`) drops its old value, and hands it to
a live borrower that holds it instead: a `??` payload, or a `: ?T prev cur`
cursor. That hand-over tells the old value apart by a key: a String's or a
Vec's buffer, or a record's first String or Vec field. An option payload,
a library handle such as a Box, and a record whose first owned field is an
option or a unit-variant enum have none. There the old value is kept back
and never released, as before #317's fix (agora #361 ended the
use-after-free that dropping it caused). Until the fix ships, give such an
owner its new value outside the borrower's scope, or bind the borrower to a
copy (`( mem_dup … )`).
