**agora #919: a `% Drop` that changes a shared Rc payload, run when a returned closure's environment is released.** A closure whose environment took such a value (`@ mkf sink H h → ( @ i ) { ^ \ → i { … } }`) runs the destructor when the closure is released. That ends no view taken through another handle on the same Rc, so a later read is of freed memory (heap-use-after-free). Until the fix ships, release such a closure before taking views of the payload its value shares.
