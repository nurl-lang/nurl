**agora #483: a closure literal capturing a lent element.** A closure written inside `~ x t { … }` that reads `( string_data x )`, or one capturing `: String e ( vec_at [String] t 0 )`, keeps no tie to `t`: its captures keep their handle copies but not the element-only sources (`__src_handles_only`), so the closure can be kept and called after `t` is released, and it reads freed memory. Until the fix ships, do not keep a closure that reads a loop element or a lent element past the container.
