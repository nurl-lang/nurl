**agora #615: a `:` binding of a value block whose tail is the block's own binding, handed on.** `: String e { : String s ( string_from … ) s }` then `( eat e )` with `eat` taking a `sink`, the same with a struct, an option or a Vec, or `^ e`: the binding is read as a block — a borrow of nothing — while the block's own binding still releases the value at the end of the scope, so it is freed twice (or read by the caller after it was freed). Until the fix ships, hand the block on directly (`( eat { … s } )`, `^ { … s }`), or bind the value outside a block.
