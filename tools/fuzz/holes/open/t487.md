**agora #487: a bare `s` view handed back through a `??` value join.**
`^ ?? ( vec_get [String] p 0 ) { T e → ( string_data e ) F → `` }`: the
arm's view of the payload `e` is a view of p's element, but the function's
lend answer does not say so, and a caller that clears p while holding the
result reads freed memory. (The `?` join, its else arm, and a `??` payload
view returned from inside an `if` are refused since the fix for #487.)
Until this is fixed too, bind the payload's view first and hand that back,
or hand back a copy (`string_from`).
