**agora #364: an enum binding given a new value inside its own match
arm.** In `?? o { MSome s → { = o … ( nurl_println ( string_data s ) ) }
… }`, the assignment drops the old value, including the payload `s`
borrows, and the read after it is of freed memory. The option form is
refused. Until the fix ships, finish reading a match payload before
giving its scrutinee a new value.
