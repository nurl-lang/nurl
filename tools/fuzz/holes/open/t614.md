**agora #614: a capturing closure bound in a scoped block under the name of an outer closure.** `: ( @ i i ) f \ … tag …` in a loop body, a `?` arm or a `: i n { … }` block, with an outer closure `f` in scope: the owned-closure list holds binding names, so the inner `f` is taken for the outer one and its environment (and what it captured) is never released — once per iteration in a loop. A value block's closure is not affected (agora #575 gives it a name of its own). Until the fix ships, give the inner closure another name.
