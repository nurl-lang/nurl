**agora #300: an element lent out of a local Vec, handed back through a
binding.** `: String e ( vec_at [String] vs 0 )  ^ e` with `vs` a local
hands back a lend of `vs`, which the return drops, so the caller reads
freed memory. The same holds for a `: ~` option bound from `vec_get`, a
copy of one by name, an option bound from a block, a `?` join or a
struct field, and a payload re-bound by name. `^ ( vec_at … )` and `?? (
vec_get … ) { T e → ^ e }` are copied and safe. Until the fix ships,
hand back a copy (`^ ( string_clone e )`), or return the call itself.
