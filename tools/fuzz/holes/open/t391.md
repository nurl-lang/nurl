**agora #391: a Vec element passed as a holder argument.** `( f 1 (
vec_at [( Vec s )] vv 0 ) src )`, with `f` pushing `( string_data src )`
into its Vec parameter: the holder has no name, so the caller ties
nothing to it, and `vv`'s element keeps a view of `src` past its end. The
same holds for a local bound from the element. Until the fix ships, pass a
named Vec as the holder, or keep the source alive as long as `vv`.
