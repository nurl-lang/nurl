**agora #878: a literal given a callee's per-call fresh-or-lent slice.** A struct literal whose slice field is the result of a call that returns a fresh slice on some calls and lends one on others (`@ Bag { ( pick_slice p k ) 1 }`) leaks the fresh one: the field is copied in as a lend on every call. Until the fix ships, bind the call's result to a name of its own first, which owns what it is given.
