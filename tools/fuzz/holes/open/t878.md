**agora #878: a struct literal given a slice that a callee hands back fresh on some calls and lent on others.** `@ Bag { ( pick T a ) 2 }`, where `pick` returns a fresh `[i | 7]` when its flag is set and its parameter otherwise, leaks the fresh slice: the literal does not take the call's per-call answer, so the field is not released with the struct. Until the fix ships, bind the call's result to a name of its own first and put that name in the literal.
