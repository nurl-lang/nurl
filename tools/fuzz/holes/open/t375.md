**agora #375: an option owner given a lend through a forwarder defined
above its caller, with an argument that is no plain owner name.** `= o (
nth vs 0 )`, with `nth` handing back `( vec_get vs k )` and defined above
the caller, keeps `o`'s old value back instead of freeing it, so it leaks.
The same happens with a field path or an alias as the argument, with the
assignment inside a closure, and with forwarders that call each other.
Defined below the caller, these are clean. Until the fix ships, define
such a forwarder below its callers, or free the old value first (`= o @
?String { F }`).
