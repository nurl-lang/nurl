**agora #418: a closure read out of a field, an element or a call's result, then called.** A call through a closure binding or a function's closure parameter answers with what the closures it may be do (agora #359). One read out of a struct field, a Vec element, a call's result or an enum payload is read by its interface only, and its plain parameters count as unchanged. So `: ( @ v ( Vec String ) ) g . h f` then `( g inner )`, where the field holds `\ ( Vec String ) x → v { ( vec_clear [String] x ) }`, ends no borrow of `inner`'s elements: a heap-use-after-free. Until the fix ships, keep a closure that changes its parameters in a binding, or a function's parameter, where it is called, or make the parameter `inout` in the closure's type.
