**agora #454: a view a callee stores through a loop element, a join or
an element binding of its own parameter, or through a `vec_each`
closure.** `@ fill ( Vec ( Vec s ) ) vv s x → v { ~ e vv { ( vec_push [s]
e x ) } }` called with `( string_data loc )`: the caller's `vv` is not
seen to hold the view, and reading it after `loc` ends reads freed
memory. Until the fix ships, push a view parameter only into a container
the callee names by its parameter, and keep the view's source alive as
long as the container.
