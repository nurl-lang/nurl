**agora #317: a `: ~` binding that owns its value, given a lent one,
never drops the value it held.** `: ~ ?Msg om ( make )  = om ( vec_get
[Msg] ms 0 )` (or `?String` with `vec_get [String]`, in an arm or not):
the old value is kept back whenever the new one is a borrow, in case the
borrow is of it, so the value `make` handed over leaks on that path.
Until the fix ships, bind the lent value to a binding of its own (`:
?Msg got ( vec_get [Msg] ms 0 )`) rather than assigning it over a
binding that owns one.
