**agora #638: closures through value blocks, the rest of #627.** Four accepted shapes that use a released environment: a closure over a value block's own String that leaves the function as the block's value (`^ { : String s … : ( @ i i ) f \ … s … f }`; the plain `^ f` is refused); a block that both assigns its closure to an outer binding and hands it out, when the outer binding is later reassigned; `= a { … a }`, a block whose tail is the assignment's own closure target; and `= a { : ( @ i i ) h \ … h }` while a `;` defer that calls `a` is armed. Until the fix ships, bind a block's closure with `:` and do not assign it elsewhere inside the block.
