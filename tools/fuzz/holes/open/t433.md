**agora #433: a closure binding reassigned by a callee through an `inout` closure parameter.** `( setf g \ ( Vec String ) z → v { ( vec_clear [String] z ) } )`, with `@ setf inout ( @ v ( Vec String ) ) f ( @ v ( Vec String ) ) src → v { = f src }`, gives `g` a clearing closure that `g`'s summary never sees. A later `( g v )` then ends no borrow of `v`'s elements: a heap-use-after-free. Until the fix ships, assign the closure to the binding directly with `=`.
