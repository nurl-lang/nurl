**agora #580: a `~` loop over a container two lends deep, grown through a shallower borrow.** With `: a ( vec_at vvv 0 )  : b ( vec_at a 0 )`, a `( vec_push ( vec_at a 0 ) … )` inside `~ x b { … }` moves the buffer the loop walks (heap-use-after-free). The loop's cursor over a container lent out of an element is now a view of those elements (AGORA-580), but two lends deep its source flattens to the outermost owner's elements, and the walk's element mark cannot tell that growth from one a level further down, which leaves the cursor alone. Until the fix ships, walk such a container by index.
