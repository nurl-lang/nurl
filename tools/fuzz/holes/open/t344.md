**agora #344: a lend through a callee defined before its caller.** A
`: ~ ?String` owner given a lend through a function that is compiled
before its caller (`= o ( first vs )`, with `@ first ( Vec String ) v →
?String { ^ ( vec_get [String] v 0 ) }`) keeps its old value instead of
dropping it, so the old value leaks. Compiled after its caller, the same
code is right. Until the fix ships, define such a function after the
functions that call it, or call `vec_get` directly.
