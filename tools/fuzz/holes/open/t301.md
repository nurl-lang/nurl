**agora #301: a view of a String parameter's buffer stored through an
`inout` argument.** `@ repoint inout W w String src → v { = w @ W { (
string_data src ) } }`, called with a String that ends before `w`:
nothing records that `w` now views it, so a later read of `. w v`, or
`w`'s `% Drop` destructor, reads freed memory. A view parameter (`s v`)
stored the same way is tracked (#259). Until the fix ships, have the
callee take the view itself (`s v`), not the String it comes from.
