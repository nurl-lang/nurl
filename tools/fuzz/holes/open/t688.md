**agora #688: a `( mem_dup x )` as an arm of a `?` value join.** `^ ? c ( mem_dup a ) ( mem_dup b2 )` - returned, or bound as `: S e ? c ( mem_dup … ) ( mem_dup … )`, also with a fresh call as the other arm - is accepted, and the copy the chosen arm made (the buffers its Strings and Vecs own) is never released: a leak, not a fault. One `mem_dup` with no join, clone calls as the arms (`string_clone`, `vec_clone`) and early-return arms are released. Until the fix ships, write the two arms as early returns (`? c { ^ ( mem_dup a ) } {}  ^ ( mem_dup b2 )`), or use `string_clone` / `vec_clone` as the arms where the type has one.
