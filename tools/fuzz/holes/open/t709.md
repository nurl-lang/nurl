**agora #709: an element's destructor that pushes into the container it is being dropped out of.** `( vec_clear [Node] ( rc_get [( Vec Node )] home ) )` where each `Node` holds a share of `home` and its `% Drop` does `( vec_push [Node] ( rc_get … . n home ) … )` is accepted, and faults: the length goes down first, so the pushes land on the elements still to be dropped — those are never dropped, the pushed ones are dropped while the `Vec` also holds them (heap-use-after-free), and a push that grows the buffer frees the storage the release is walking. `vec_truncate` and `vec_retain` drop their tail the same way, and `deque_clear` writes over its second run. No panic is involved; an `Rc ( Vec T )` or a `Weak` upgraded in the destructor is all it takes to reach a container that lives on. Until the fix ships, a destructor must not add to (or grow) the container that owns the value it is dropping: collect what it wants to add and push it after the clear returns.
