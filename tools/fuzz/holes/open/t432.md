**agora #432: a defer in an arm not taken that binds a value of its own.**
`? c { ; { : ( Vec i ) g ( vec_new [i] ) … } } {}` with `c` false: the
body never runs, but the function's cleanup still releases `g` from a
slot the body never filled (a misaligned read, or a crash). A defer that
runs, or one armed on every path, is clean. Until the fix ships, declare
a defer body's own Vec or String only in a defer that is armed on every
path, or allocate it before the `;` and use it in the body.
