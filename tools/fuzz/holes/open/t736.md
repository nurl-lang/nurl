**agora #736: a closure stored in a struct field and run by a helper changes an Rc's payload.** A closure capturing `r`, stored in a struct field (`: C { ( @ v ) go i n }`) and run by a helper that reads the field (`@ runc C c → v { : ( @ v ) g . c go ( g ) }`), replaces `r`'s payload beside a slice taken through `r2` (a clone of `r`), which then dangles (heap-use-after-free): the closures a struct holds carry their captures to it, not their effects. Until the fix ships, take views through an Rc's other handles again after handing a value holding such a closure to a function that may run it.
