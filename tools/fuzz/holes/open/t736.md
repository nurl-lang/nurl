**agora #736: a holder handed to a callee beside another handle on the Rc its closure changes.** A struct, option or Vec holding a closure that replaces an Rc's payload, handed to a function together with another handle on that Rc (`( viewrun @ C { \ → v { ( rc_set r … ) } 1 } r2 )`), where the function takes a view through the handle and then runs the holder's closure, reads freed memory (heap-use-after-free). A closure handed that way directly is refused by the exclusive-call check (h274). A holder is not asked it: it gathers every closure stored into it, a server's tools, so every call it is handed to would be judged to run them all, and registering one more tool on such a server would be refused. Asking it precisely wants a summary of what a callee may run of what a parameter holds. Until the fix ships, do not hand a callee a value holding a closure together with another handle on an Rc that closure changes.
