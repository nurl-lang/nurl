**agora #630: three exits that release the wrong thing.** A `^` from inside a value block with `;` defers armed before and after the statement (heap-use-after-free in the epilogue); a value block returned straight, `^ { … t }`, whose tail binding is a cursor of an element of another block binding (the caller reads freed memory; bound first and returned by name it is copied); and, with no block at all, a defer, an early `^`, then a later binding with a defer of its own (the early return releases the binding that was never made). Until the fix ships, return from the statement level, bind a block's value before returning it, and declare every binding a defer reads before the first early return.
