**agora #655: a `;` defer in a loop body.** A defer runs once, at function exit, if its `;` was reached in any round. A later round that leaves the loop or the function above the `;` (a `break`, a `^`) releases that round's bindings itself, and the defer, armed in an earlier round, then reads one of them (heap-use-after-free); a `^` written above the `;` does not run the defer at all though an earlier round armed it; and each round's value that the defer keeps, but the last, leaks. Until the fix ships, register a defer outside the loop, above it, and have it read bindings made outside the loop.
