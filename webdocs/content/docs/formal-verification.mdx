NURL's single-owner memory model ([Memory and Ownership](./memory-and-ownership), [`docs/MEMORY.md`](https://github.com/nurl-lang/nurl/blob/main/docs/MEMORY.md)) is backed by a mechanized **Lean 4** soundness, leak-freedom, and data-race-freedom proof in [`formal/`](https://github.com/nurl-lang/nurl/tree/main/formal) — over **60,000 lines of Lean 4** (live counts in the explorer below and in [`formal/BLUEPRINT.md`](https://github.com/nurl-lang/nurl/blob/main/formal/BLUEPRINT.md)), with **zero `sorry`s** and only Lean's three standard axioms (`propext`, `Classical.choice`, `Quot.sound`).

Use the interactive explorer below to inspect the proof at two levels:
1. **For Everyone (Tab 1 — Visual Story & Simulator):** Step through concrete NURL programs to see how the compile-time context $\Gamma$ (`Typing.lean`) and runtime memory store `Mem` (`Semantics.lean`) interact, why `vec_push` kills `Slice` views while preserving element borrows (`Eff.kills`), and how panic unwinding (`panic_unwind`) frees every owned allocation via the drop journal.
2. **For Mathematicians & PL Researchers (Tabs 2–4 — Lean Blueprint DAG, Code Browser & Hole Corpus):** Explore the interactive **Lean Blueprint** theorem/module dependency graphs, browse every **Lean 4 declaration** of A1, A2 and A3 with cross-referenced dependencies, and inspect every soundness hole probe in the corpus.

## Proof Roadmap & Scope (`formal/CLAIM.md`)

The mechanization is organized into phases:

| Phase | Scope | Key Theorems | Status |
|---|---|---|---|
| **A1** | Core single-threaded calculus: owned `Vec` trees (a `String` is a `Vec` of bytes), moves and drop flags, `in` / `inout` / `sink`, borrows and `Slice` views, buffer reallocation (`Eff.realloc`), element drop (`Eff.drop`), function summaries (`CallT`, `FnOK`). | `A1.soundness`, `A1.memory_safe` | **Proven** |
| **A2** | Full single-threaded calculus: A1 + inline structs (`Ty.prod`) and enums/options (`Ty.sum`) with field-precise paths, closures and trait objects as packages (`Val.pkg`, `Rhs.pack`, `Stmt.callc`) with captures by handle and by name (`Kind.name`), panics with unwinding and `recover` (`Stmt.catchR`), the drop journal, and **complete leak freedom**. | `A2.soundness`, `A2.memory_safe`, `A2.no_leak_end`, `A2.no_leak_panic` | **Proven** |
| **A3** | Concurrency & data-race freedom: threads that move values (`spawn`, `join`; an M:N fiber is a thread of the model), `Send` / `Sync`, `Arc`, `Locked [T]` / `Mutex`, `RwLocked [T]` with its `% Frozen` read guards (`% NotSend`), `Atomic`, channels, library handles whose copies are one state under the crossing check (`SendCheck`), closures and trait objects across threads, and module globals set by their `make` before `main`. Deadlock freedom is not claimed. The stated claim also says race freedom sees every cell access (`CellAdequate`). | `A3.claim_full`, `A3.claim_made_full` (with `A3.claim`, `A3.claim_made`) | **Proven** |
| **B** | Semantic soundness of the standard library's `unsafe` foundation (`Vec`, `String`, `HashMap`, `Rc` + cycle collector, `Arc`, channels). | — | Planned |
| **C** | Compiler verification: `nurlc` emits proof certificates for accepted programs, checked by a small verified validator. | — | Planned |
| **D** | Codegen translation validation: drop insertion, drop flags, and the panic drop journal preserve the formal operational semantics. | — | Planned |

## Verifying the Proof Locally

The Lean 4 proof uses toolchain `leanprover/lean4:v4.35.0` with **zero external library dependencies** (Lean 4 core library only). To build every module and verify that the crown theorems depend only on standard axioms:

```bash
cd formal
./check.sh
```

`check.sh` runs `lake build`, rejects any occurrence of `sorry`, `admit`, or custom `axiom` across `A1/`, `A2/`, and `A3/`, and executes `lake env lean Check.lean` (`#print axioms A1.memory_safe`, `A2.memory_safe`, `A2.no_leak_end`, `A2.no_leak_panic`, `A3.claim`, `A3.claim_made`, `A3.claim_full`, `A3.claim_made_full`).
