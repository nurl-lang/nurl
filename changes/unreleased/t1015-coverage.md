### Added

- **nurl-cert: each function's own coverage status, and a coverage table** (AGORA-1015, M2 part 1). The translation no longer stops at the first function it does not cover. It goes on through the program, and the manifest's `coverage.functions` gives each of the program's own functions its own status and reason: `unsupported` with that function's reason, `error` where the translation stopped on an internal error, and `open` for a function that translates in a program that does not. The program's verdict and every claim are as before: a program with an unsupported function is refused with the first one's reason, and its claims stay `open`. `nurl-cert coverage DIR` sums the bundles `DIR/*.cert` into a Markdown table: programs by verdict, functions by status by count and by source lines, and the reasons for `unsupported`, most frequent first. `packages/nurl-cert/tests/coverage.sh` runs it over the certify corpus, the hole sweep, `examples/`, the compiler tests and `packages/`, and writes the table into `formal/README.md`.

### Performance

- **nurl-cert reads a core IR with fewer allocations** (AGORA-1015). A statement line is no longer split into tab columns, and no longer kept as a second copy beside its words: the line's kind is read from its first column where it lies. Translating nurlc's own core IR (9.9 MB, 3772 functions) takes 0.63 s against 0.94 s, with a peak of 446 MB against 569 MB, and the hole sweep's 4445 core IRs translate in 9.2 s against 10.1 s, with the same output byte for byte. That pays for the coverage above: certifying nurlc, which now translates all 3772 functions where it stopped at the first one, takes 11.43 s against 11.37 s, with a peak of 512 MB against 629 MB. The 62 certify programs take 45.02 s against 44.99 s (best of 3, alternated), with the same peak memory. `nurl-cert translate` and `verify` still stop at the first function they do not cover, because they need only the verdict.
