### Changed

- **The formal proof shows that an argument's views stay valid while a through-changing call changes what they point into, and that nothing else live in the caller reaches it** (AGORA-937, stage 3c, fourth part). When a change rewrites a node strictly inside a node a region reaches, the argument's view of the region's buffer is still valid through the region afterwards: same bounds, and the node is still well-formed (`RegionViewAt.keep_inner`). After the call's entry kill, no live caller binding other than the arguments depends, by any kind a drop ends, on the roots the arguments hold views of (`thruPre_live_nohit`). No typing rule uses these yet, and every theorem statement is as it was. Compiler, runtime and NURL source are unchanged, so compile time and run time are byte-for-byte as before.
