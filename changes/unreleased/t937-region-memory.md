### Changed

- **The formal proof says what a parameter's region reaches in memory** (AGORA-937, stage 3b, first part). Typing a through-changing call that passes views of the caller's memory needs the region its argument's views point into to be something the memory invariant can speak of. `A2/RegionMem.lean` defines that region as the set of buffer addresses of the views a value stores. A region reaches the node currently at one of those addresses, which is the existing case for a borrowed view generalised, so what lands through it lands as through any other dependency. It proves the facts the call's entry needs: an argument whose views are valid has each of them valid through its region; each address reaches exactly one node; and borrows derived through a region compose as through a root. No typing rule uses it yet, and every theorem statement is as it was. Compiler, runtime and NURL source are unchanged, so compile time and run time are byte-for-byte as before.
