### Changed

- **The formal proof covers a closure whose code changes elements through a borrow of its own local** (AGORA-395). A2 used to refuse any closure code that changes a `Vec`'s elements through a borrow (Agora #295). nurlc accepts such code: a closure that pushes through `( vec_at loc 0 )` of a local it made. A2 now types it when three conditions hold: the closure's interface is such code too, its environment holds no views, and it takes the environment lent. A call through the closure then passes no argument holding views, as a direct call into such a function does. The calculus's `.callc` names the interface it calls, so this propagates to the callers of any function that makes such a call. This changes the calculus only; NURL source is unchanged. `A2/ThruClosureWitness.lean` types such a program. `formal/CLAIM.md` moves the case into the claim and still lists what remains outside: a call that passes an argument holding views (nurlc accepts one), an environment that holds views or is handed over, and a destructor.
