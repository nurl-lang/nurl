### Fixed

- **A closure that gives a captured binding a borrowed value no longer leaves it pointing at freed memory** (AGORA-872). Inside a closure, `= o ( id other )` with `o` captured by the closure and `other` a local or a parameter of the closure left `o` borrowing `other`, which is released when the closure returns. Reading `o` after the call was a heap-use-after-free. A captured binding is now treated as a place outside the closure, as an `inout` parameter is: what a call or a `?`/`??` join lends it of a local or a parameter of the closure is copied in, and the binding owns the copy. This covers a pick, a generic, a value block's tail, a loop and `recover`. A lend of another captured binding is left as it was: it aliases, as the same line outside a closure does. A call that hands the binding back its own value (`= o ( f o )`) still makes no copy. A value of a type with no copy (a struct with its own `% Drop`) cannot be copied in, so that store is now refused, as it is for an `inout` parameter.
