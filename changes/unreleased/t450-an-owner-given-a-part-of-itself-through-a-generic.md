### Fixed

- **An owner given a part of its own value through a generic compiled later keeps a copy of that part** (Agora #450, part A). `= o ( first o )`, with `first` handing back `( vec_at [N] . x kids 0 )`, dropped o's old value with the element inside it, and o read freed memory. At the `=`, first's lends wait on `vec_at`'s instance, so nurlc could not tell that the result may be a part of o. The callee's module-end `part` answer for o's position now decides: a lent result that is not o's old value is copied, o owns the copy, and the old value goes. The same holds through a helper (`( kid0 . x kids )`), and a run that hands back a fresh value is not copied. A part bound first and then handed back (`: Tr c ( vec_at … . t kids 0 )  = t ( tfwd c )`) is still open: `tools/fuzz/holes/open/t450.md`.
