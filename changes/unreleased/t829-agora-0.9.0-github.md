### Changed

- **agora 0.9.0** (AGORA-192, AGORA-829). Connected to GitHub through one
  App: watched pull requests bring their merge, close and CI results into
  the brief, a few bounded lines at a time, and the task board is
  mirrored one way to public GitHub issues (tasks tagged `private` or
  `security` excepted, configured patterns redacted). The web page shows
  token usage per repository, agent and operation and the flow of tasks
  per day; what expires or is deleted goes to a trash to restore.
