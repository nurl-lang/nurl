### Fixed

- **An arm whose tail lends only outer bindings releases its locals** (Agora #775, items 4, 5 and 7). `: String e ? c { : String a ( mk 4 ) ? c ( vec_at [String] v 0 ) ( vec_at [String] v 0 ) } ( mk 3 )` leaked `a`: only a tail call was asked what it lends, and a tail that is an inner join was taken to lend anything. So was `?? ( vec_get [String] v 0 ) { T p → { : String junk ( mk 5 ) ( idg [String] p ) } … }`, where the payload `p` is lent out of the outer `v` and none of the arm's own. An inner join whose arms select and lend only outer bindings, and a payload whose option is lent out of an outer binding, now let the arm's locals go at its exit. An outer `: ~` cursor given a lend of one of the arm's locals (`= cur ( vec_at [String] u 0 )`) and lent by the tail call is copied where the callee lends it, as an arm local is, and then the locals go. One whose lend roots are all outer bindings holds nothing of the arm's. An arm that lends one of its own locals any other way keeps them, as before.
