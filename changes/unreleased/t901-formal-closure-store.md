### Changed

- **The formal proof covers a store through a borrow of an element that holds both a view and a closure** (AGORA-901). `StmtT.editBV`, a `vec_push` or `vec_set` through a borrow such as `( vec_at vv 0 )` of elements that hold views, took no element whose type holds a closure. It now does when the borrow, and every owner of a view-holding type the element may land in, already holds whatever the stored value captures by name. A closure that captures by value captures nothing by name, and that is what nurlc stores (`compiler/tests/closure_beside_view_stored_through_borrow.nu`). nurlc refuses a closure that captures a stack binding by name before it can reach any Vec. The proof rests on the invariant that no closure's environment holds what a clean borrow reaches (`MInv.pkgFree`): the node the store rewrites lies in no package. `A2/EditBVFnWitness.lean` types such a program and proves it memory-safe and leak-free. `formal/CLAIM.md` loses this case from its list of what lies outside the claim.
