### Changed

- **Growing one element lent by a call no longer ends every view of its container** (AGORA-374, docs/MEMORY.md §2.10). `( string_push_str ( vec_at vs 0 ) … )` moves element 0's buffer alone. A `Slice` of `vs` read after it stays, so does a view of another element named by a number literal (`( string_data ( vec_at vs 1 ) )`, `( string_bytes ( vec_at vs 1 ) )`), and so does the same through a forwarder of your own, or a push onto each element in a loop bounded by a slice of `vs`. Before, every one was refused ("a value lent from it was passed to 'string_push_str', which may move or free its buffer"). The workaround of binding the element first is no longer needed. A view of the grown element itself still ends. So does a view of another element where the index is not a literal, or where something between the view and the call may reorder the container (`vec_swap`, a closure that runs, a function that may change it, on any path). New tests `elem_lend_grow_keeps_other_views`, `diag_borrow_elem_lend_grow_after_a_swap`, `diag_borrow_elem_lend_grow_after_a_swap_on_one_path`, `diag_borrow_elem_lend_grow_after_a_swap_in_a_loop`, `diag_borrow_elem_lend_grow_after_a_closure_swaps`, `diag_borrow_elem_lend_grow_index_not_a_literal`. Compile time: self-compile work +0.02 %, peak RSS +0.2 %, from the new facts in functions that hand a lent element on.
