### Fixed

- **A slice is an owned value wherever it goes** (Agora #545). Which slice a function owned was a list of names kept while the function compiled, so a slice that left its name was freed twice or by the wrong owner: an owned binding stored into a struct or an enum payload (`@ Hold { q }`), bound a second time (`: [i r q`) or returned through another name was a double free; `= d p` over a parameter freed the caller's buffer; an `inout` slice given a parameter left both owners one buffer. A `[T` is now owned by its type, as a `String` or a `Vec` is: the binding, field or payload that holds it releases it once, a move empties the binding it leaves, and a slice that is only borrowed (a parameter, a field of a live value) is copied into whatever comes to own it — a parameter in a literal the function returns is handed over by the caller, as a `String` is.
- **A function that returns its own slice on one path and a parameter on another frees nothing it was shown and leaks nothing** (Agora #540). `? c { ^ p } {} ^ [i | 1 2 3]` made the whole function's result unowned, so the literal leaked on every call that took that path. A returned parameter is a copy now, so the result is the caller's on every path.
- **A slice is released whoever made it** (Agora #510). A slice returned by a function defined below its caller, or by a generic instance, was never freed, and a struct whose field is a slice owned nothing unless a literal in the same function gave it one. An option, a result or an enum payload of a slice, a slice in an argument list and a discarded slice result leaked the same way.
- **A panic that unwinds over a slice releases its elements** (Agora #509). Under `recover` the unwind freed an owned slice's buffer and left the Strings, Vecs and closure environments in it; a slice temporary in the argument list of the call that panicked was not freed at all.
- **An owned slice goes on releasing its elements after one's destructor panics** (Agora #545, the slice sibling of #608). Under `recover` a panic in an element's destructor left the slice's drop: the elements after it ran no destructor and they and the buffer leaked — for a slice in a binding, a struct field, an option, a `Vec` or another slice. The release continues with the elements after it, in index order and once each, then frees the buffer, and only then does the panic go on. A struct whose field is a slice of `% Drop` values is dropped field by field, as one holding a `( Vec T )` of them is: nothing dropped it before, panic or none.
- **A panic in the destructor of the value an assignment replaces leaves the target holding the new value** (Agora #621). `= b ( make )` dropped the old value where it stood, while `b` was still registered as holding it: when its destructor panicked under `recover`, the unwind dropped it a second time (a use after free), the new value was lost, and an owner outside the `recover` was left holding the freed one. The new value is stored first and the old one is dropped from a temporary, so the target holds the new value whatever the destructor does — a binding (a struct, a `Vec`, a slice, an option, an enum), a field, a nested field, a slice element, an `inout` parameter and a binding a closure captured. A closure binding given a new closure releases the environment it owned the same way, after the store: a capture's destructor that panicked left the binding (a local, an owner outside the `recover`, the caller's closure behind an `inout` parameter) holding the closure whose environment was being freed, and the new environment was nobody's. Where nothing panics the order is what it was: the old value is dropped at the assignment.
- **What a native slice's elements view is followed** (Agora #545). A slice literal holding a view (`[s | ( string_data text ) ]`, or a struct with one), a view stored into an element (`= . ws k ( string_data text )`, also by a callee the slice was handed to) and a slice literal a function returns over its parameters' views were tracked nowhere: the slice was read, or its elements' destructors run, after `text` grew and freed the buffer they pointed into. The slice now depends on what its elements view, as a struct does on its fields' views and a `Vec` on its elements': reading it after the source may have moved is refused, and so is giving a slice of `% Drop` view holders a view of a binding declared after it. A slice whose elements own their values is unaffected.
- **A value stored through a cursor leaves the binding the cursor is over** (Agora #545). `: ~ String c q` then `@ G { c }`, a field store or a `vec_push` of `c` put `q`'s buffer into the new owner and left `q` readable: once that owner was dropped, `q` read freed memory. `q` is stored there now as if it had been named, for a `String`, a `Vec`, a slice and a struct alike, and reading it afterwards is refused.
- **An `inout` binding given a slice literal, or a value block that ends in a literal, releases the value it held** (Agora #545). `= p [i | 3 4]` over an `inout [i`, and `= p { … @ R { … } }` or `= p { … [i | z 4] }` over any `inout` owner — a struct, an option, a slice — stored the new value over the caller's old one, which nobody released: a leak on every call.
- **An `inout` argument its callee keeps is consumed in the caller** (Agora #545). A callee that returns its `inout` parameter in a literal, pushes it into a container or stores it into a field takes the value over, and the caller already stopped releasing it — but could still read it, after the new owner had freed it. Reading the binding after such a call is refused, as it is for an argument passed by value.
- **A payload returned out of a match on a binding a call filled is taken out of that binding** (Agora #545). `: Msg m ( mk ) ?? m { Both c → { ^ c } … }` handed `c` back while `m` still released it, and the caller read freed memory, whenever `mk` is a call that tells its caller whether its result was lent. The match takes the payload out of `m` on the runs where `m` owns it.
- **A `??` over a literal releases the literal** (Agora #545). An option, result or enum literal matched where it is written (`?? @ ?[i { T ( mk ) } { … }`) was never dropped.
- **A value nothing names is released where it is read through** (Agora #545). `. ( mk ) length`, an element or a field of a call's result or of a literal, and a `~` loop over a field of one leaked the temporary; a field of a `% Drop` temporary read in a loop body was released twice. The read releases the temporary once it is done with it, or gives it an owner for the rest of the scope where what it read is still inside.
- **A value block that ends in an owned slice hands it over once** (Agora #545). A literal, a call, the block's own binding or a struct holding a slice as the block's value was freed by the block and by what the block was the value of, or by neither; a slice returned past a `;` defer or out of a loop body is the caller's now and the ones left behind are released.
- **`^ { x }` hands the binding back as `^ x` does** (Agora #545). A parameter, a loop's element or a binding that borrows, returned as a value block's value, went back as the function's own, and its owner and the caller both released it.
- **`^ ? c loc p` over a local and a parameter gives the caller its own value on every path** (Agora #545, #540). The local is handed over, the parameter copied, and the function releases the local on the paths that did not return it; it was a leak on one path or a double free on the other.
- **A `~` loop's element returned out of a container the function drops is the caller's own** (Agora #545). The element went back as lent while the frame dropped the container it was read out of: a use after free, or a double free. It is taken out of its slot, or copied where it cannot be taken; out of a parameter it is still a lend the caller copies.
- **An element store whose value is read out of another element or a field stores a copy** (Agora #545). `= . xs 0 . xs 1` moved the value as it was, so two slots owned one buffer. The slot it is read from keeps its value and the element the store replaces is dropped; a value that cannot be copied (a `% Drop` with no clone) is refused there.
- **`= h ( bump h )` keeps what the result lends back** (Agora #545). Where `bump` hands back a literal built over a field of its parameter, the assignment kept the old `h` whole and that field leaked — a String, a Vec and a slice alike.
- **A literal written as an argument, over a binding, to a callee that hands its parameter back is owned by the result** (Agora #545). `( keep @ H { a 1 } )` leaked the moved-in `a` when the result was dropped or discarded.
- **`^ # T a`, a cast of a binding to the type it has, is `^ a`** (Agora #545). The return took it for a read through a cast, lent by nobody, and the local's value leaked — a String's, a struct's and a slice's.
- **A returned literal has one owner** (Agora #635, #545). `^ @ Row { . p name ( string_from … ) }` — a field lent out of a parameter beside a field of the literal's own — went back lent as a whole, and its own field was released by nobody: it leaked, in a struct, a variant, an option, a result and a literal nested in one. The lent field is copied there, so the caller owns the literal whole; a literal lent throughout stays lent and copies nothing. A lent field that cannot be copied (a `% Drop` with no clone) beside an owned one is refused where it stands.

### Changed

- **A slice moves** (Agora #545). `: [i r q` over a local slice, `= e q`, a struct or enum literal built over `q`, and `q` handed to a `sink` parameter move the buffer, and reading `q` afterwards is refused as a use of a moved value — it read freed memory before. `: ~ [i c q` is a cursor over `q`, as it is for a `Vec`. A struct with a slice field moves as any owning struct does.
- **An owned slice, or a struct holding one, can be passed to a `sink` parameter** (Agora #545). The limit that sent such code to a `Vec` is gone.
- **A store into an element of the slice a `~` loop walks is refused when the slice owns its elements** (Agora #545). `~ x names { = . names 0 … }` released the element the loop was reading. Loop over the indices, or store after the loop; a slice of plain data is unaffected.
- **A slice built from raw parts is `unsafe`** (Agora #545). `@ [T { pointer length }` takes the buffer behind the pointer for its own and frees it, so safe code may not write it; an `unsafe` function that does hands the buffer over.
- **A slice temporary passed as an argument is released by the caller** (Agora #545). `unsafe` code that frees a slice parameter's buffer by hand frees it a second time: let the owner release it, or take the parameter as `sink`.
- **A slice parameter placed whole in a returned literal is taken over, as a `String` is** (Agora #545). `@ wrap [i p → H { ^ @ H { p } }` moves the caller's argument into the result, and reading the argument's binding after the call is refused; pass `( mem_dup q )` to keep it.
