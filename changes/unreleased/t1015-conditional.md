### Added

- **Conditional memory-safety certificates, the proof** (AGORA-1015, M2 part 2; `formal/C/Complete.lean`, phase C15). A program whose translation leaves some functions out can now get a theorem, not only `open` claims. `P` holds a stub at each assumed function: its signature, the functions it calls and whether it changes elements through a borrow, all of which the core IR gives without translating the body. `certOK2BA` decides the rest of the program, and `cert_safe_cond`, `cert_leak_end_cond` and `cert_leak_panic_cond` give `M.safe` and `M.leak` for every completion of `P` in which the assumed functions are well-typed. The real program is one of those completions. Typing over the stubs is typing over any completion (`StmtT.complete`, `FnOK.complete`), and `ThruFn` is the same over both (a lemma, not a hypothesis). `cond_witness_safe` instantiates the claims for a real two-function program, so the hypotheses can hold. For a program with no assumed function the claims are the old ones. Standard axioms only. The design is `docs/dev/CONDITIONAL_CERTIFICATES.md`. The translator, `elabIR` and the bundle take it up next.
