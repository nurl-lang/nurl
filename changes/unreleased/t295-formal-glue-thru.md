### Changed

- **The formal proof covers drop glue whose code changes elements through a borrow** (Agora #295). A struct that holds a destructor value gets drop glue, and so does one with a `% Drop` of its own, which its glue runs. A2 used to refuse glue that changes a `Vec`'s elements through a borrow, directly or through that `% Drop`. nurlc accepts such a struct: its `% Drop` pushes through `( vec_at loc 0 )` of a local it made. A2 now types it when the type holds no views, on the same terms as a destructor: the glue's call at the frame's end, and its call of the `% Drop`, pass no argument holding views. No new invariant. This changes the calculus only; NURL source is unchanged. `A2/ThruGlueWitness.lean` types such a program, memory safe and leak-free. `formal/CLAIM.md` moves the case into the claim; through-changing drop code of a type that holds views stays outside.
