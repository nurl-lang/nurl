### Changed

- **The formal proof gains the first piece of typing a through-changing call that passes views of real memory** (AGORA-937, stage 3a). Such a call may move buffers inside the memory its arguments hold views of, so the caller's other bindings that reach that memory must be dead while the body runs. `A2/ThruPre.lean` defines that entry kill, `thruPre`: a drop on each root the arguments hold views of, applied to every binding but the arguments. It proves that the kill only ends bindings, and so keeps the context well-formed, its domain, modes and types, fresh borrows' sources, and every binding a closure names. On AGORA-933's `( f1 vv )` it ends `s2`, the caller's view of `w`'s element, and keeps `vv` and `w`. No typing rule uses it yet, so no program's typing changes, and every theorem statement is as it was. `formal/A2/THRU_STAGE3_DESIGN.md` gives the plan for the rest of stage 3: regions lifted as ghost bindings, as names are; a ghost store for the memory invariant; and then the call premise. NURL source is unchanged.
