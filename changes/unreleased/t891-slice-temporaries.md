### Fixed

- **A slice a call makes and hands straight to another call is released** (AGORA-891). Examples: `( ln ( mk ) )`, a slice made in a loop, in a closure call or in a callee defined later, a slice handed to a generic function, a slice of Strings, Vecs or closures, and a call that panics under `recover` while it holds one. Before, nothing released a slice temporary: only handles were treated as temporaries. It now goes by the inner call's answer, as a binding of it does: it is released after the call unless the callee keeps it, sinks it or hands it back. One handed back, as in `: [i x ( pick ( pick a f ) F )` or `: [i x ( id ( mk ) )`, is owned by the result on the runs it was fresh. On the runs the callee returns a new slice of its own, the temporary goes after the call. A result the callee lends in part out of the temporary is copied, as a String's is, so `( walk ( mk ) 3 )` through a recursive forwarder is not refused.
- **`= x ( f … )` into a `: ~` slice no longer double-frees** (AGORA-891). Example: `= x ( pick a f )`, where `pick` returns a new slice on some runs and its parameter `a` on others. `x` kept its old ownership flag, so it released `a`'s buffer under `a`, and its own old value leaked. It now owns the new value by the call's answer, and releases its old value unless the new one lies inside it (`= x ( id x )`).
- Still open nearby: a `sink` slice parameter (AGORA-892), a `?` join of slices with a call's fresh slice on one arm (AGORA-893), a closure handing a slice temporary back (AGORA-894), and a slice temporary its callee keeps in what it returns (AGORA-895).
