### Fixed

- **Certificates on Windows** (AGORA-1031). `nurlc --list-sources` gives each source file's length and then its bytes. On Windows the C runtime's stderr wrote each `\n` as `\r\n`, so the bytes no longer matched the length, and every `nurl-cert certify` stopped with "a source file on disk is not the bytes nurlc compiled". nurlc now writes stdout and stderr untranslated whenever a program reads its output byte for byte (`--list-sources`, `--emit-core`, `--unsafe-report`). A new runtime function, `nurl_stdio_binary`, does that on Windows and nothing elsewhere. The core IR, the LLVM IR and the records are now the same bytes on Windows as on Linux. nurl-cert also took a path like `C:/…` for a relative one: it now knows drive and share paths. Its test suite runs under Git Bash on Windows (`nurl.bat`, `.exe`), and a Windows job in the certify workflow certifies and verifies an accepted program, a refused one and a threaded one. Lean runs natively there.
