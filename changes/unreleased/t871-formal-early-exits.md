### Added

- **The formal proof covers `break`, `continue` and an early `^`** (Agora #871). A2's calculus has blocks, an `exit n` that leaves `n + 1` of them in one step, and `while T` as a loop left only by its exits. Every scope an exit leaves ends on the way, with its drops and destructors run as at the scope's own end. Typing carries the exits a statement may take, and a block's end says no more than the state each exit leaves from. Preservation, progress, the no-leak theorems, the renaming lemma and A3's thread proofs all cover the new forms, and every crown theorem keeps its statement. Before this, the calculus had none of these exits: a loop was left only from its head, and a function returned only at its body's end. A new module, `ExitWitness`, has three worked examples, each run memory-safe and leak-free: a `break` out of `while T` that drops a live owned `Vec`, a `continue`, and an early `^` across a scope with its caller. Frames that are not scopes, such as a `recover`, a lock check-out or an element hand-over, take no exits. In source, each of them holds a call.

### Fixed

- **A `break` or `continue` in a closure body now gets a clear compile error** (Agora #871). This applies to a `break` or `continue` in a closure literal written inside a `~` loop, outside any loop written in the closure body. The compiler used to emit a branch to the enclosing function's loop label from inside the closure's own function, so the build failed in clang with `use of undefined value '%loop_exit_3'`. nurlc now refuses the program and names the reason. A closure body is a function of its own, so a `break` or `continue` there leaves only a loop written inside it. That is also the formal model's rule: an exit never crosses a call frame. No program that compiled before is affected.

- **The unikernel runtime no longer corrupts the heap at a coroutine switch inside a `recover`** (Agora #880). Each coroutine reserved 14 words for its recovery state, while the state had grown to 16 (Agora #623). Every switch inside a recover extent therefore wrote 16 bytes past the end of the coroutine's heap block, and an occasional SIGSEGV followed (`dst_flagship` on the nolibc corpus, about 1 run in 40). The slot size now has a single definition shared by the hosted and the bare runtime (`stdlib/nurl_rctx.h`). The bare runtime also checks its slot against the state's real size at the first coroutine, so any future drift stops every run instead of corrupting memory.

### Performance

- **Loops over a `Vec` of structs keep the length and the data pointer in registers** (Agora #879). An element of a struct type, read or written through the buffer, now carries the same "element, not the control block" alias tag that a scalar element already carried. A `vec_put` therefore no longer makes the next `vec_at` reload the length and data pointer and repeat its bounds check after every store. The bounds check itself stays. The tag's claim, that a control block is never another tree's buffer, is now a theorem of the calculus: `A2.ctl_ne_data` in `formal/A2/Layout.lean` covers every tree the store owns. bench/safe_record_array runs 0.88% fewer instructions and about 0.9% faster (median of 41 interleaved runs pinned to one CPU); the other benchmark binaries are byte-identical.
- **nurlc's peak memory on large modules is 14% lower** (Agora #879). Type definitions are now moved to the top of the module in place. Before, the reordered module was a second full copy, alive beside the first while the module was emitted, which was the compile's peak. On a self-compile against main, peak RSS goes from 284 MB to 245 MB (−13.7%), page faults fall by 11.9% and wall time by 2.2% (medians of 11 interleaved runs pinned to one CPU). The generated module is byte-identical.
