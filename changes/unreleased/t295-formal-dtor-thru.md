### Changed

- **The formal proof covers a destructor whose code changes elements through a borrow of its own local** (Agora #295). A2 used to refuse any destructor that changes a `Vec`'s elements through a borrow. nurlc accepts such a destructor: a `% Drop` that pushes through `( vec_at loc 0 )` of a local it made. A2 now types it when the type it takes holds no views. The call its frame's end makes then passes no argument holding views, as a direct call into such a function must. No new invariant was needed: a `letd` of a type that holds no views is unarmed, and an unarmed value is revived at its frame's end holding nothing, whatever the `letd` recorded. This changes the calculus only; NURL source is unchanged. `A2/ThruDtorWitness.lean` types such a program, memory safe and leak-free. `formal/CLAIM.md` moves the case into the claim; a through-changing destructor of a type that holds views, or reached through glue, stays outside.
