### Fixed

- **A `sink` callee that grows a `Vec` it reaches through a slice its parameter holds no longer leaves its caller's views of that `Vec` reading freed memory** (AGORA-949). AGORA-933 closed this for a parameter that is lent; for one the callee takes over (`sink`), nurlc still ended nothing. With `vv` a `( Vec ( Slice ( Vec i ) ) )` holding a slice of `w`, `( f vv )` with `f sink … vv` growing `( slice_at ( vec_at vv 0 ) 0 )`, directly or through a callee it hands `vv` to, moved the buffer of `w`'s element, and a view of that element the caller read after the call read freed memory. Now the caller's views of it end at the call, as for a lent argument: read the view before the call, or keep a copy that owns its data (`slice_to_vec`). NURL source that reads no such view after the call is unchanged.
