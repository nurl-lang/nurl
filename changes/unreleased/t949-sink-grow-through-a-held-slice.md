### Fixed

- **A callee that grows a `Vec` it reaches through a slice its argument holds no longer leaves its caller's views of that `Vec` reading freed memory, however the argument is written** (AGORA-949). AGORA-933 closed this for a binding that is lent. A binding handed to a `sink` parameter, a call's result (`( f ( identity vv ) )`, `( f ( wrap ( slice_from_vec w ) ) )`), a join of such, and a struct field (`( f . h vs )`) still ended nothing. With `vv` a `( Vec ( Slice ( Vec i ) ) )` holding a slice of `w`, a callee growing `( slice_at ( vec_at vv 0 ) 0 )` moved the buffer of `w`'s element, and a view of that element the caller read after the call read freed memory. Now the caller's views of it end at the call, as for a lent binding: read the view before the call, or keep a copy that owns its data (`slice_to_vec`). NURL source that reads no such view after the call is unchanged.
