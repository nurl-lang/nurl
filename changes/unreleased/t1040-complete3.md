### Changed

- **A single-threaded conditional certificate loads no A3** (AGORA-1040). `formal/C/Complete.lean` (C15) imported `C.Cert3` for its threaded part, so a conditional certificate of a single-threaded program loaded all of A3. The threaded part (`C.certOK3BA`, `C.AssumedOK3`, `C.cert3_*_cond`) is now `formal/C/Complete3.lean`, and the witnesses (`C.cond_witness_*`, `C.cond3_witness_*`) are `formal/C/CompleteWitness.lean`, which no certificate imports. Names are unchanged, and `formal/check.sh` prints the same axioms. A threaded conditional bundle's Claims.lean imports `C.Complete3`; a single-threaded one still imports `C.Complete`. Such a single-threaded certificate's Lean check loads 250.6 MB of `formal/`'s build where it loaded 319.5 MB, N.cap included. A threaded conditional bundle certified before does not verify with this `nurl-cert verify`, because its Claims.lean's import changed: certify it again. `formal/` builds `C.Complete3` too (`lake build … C.Complete C.Complete3 …`).
