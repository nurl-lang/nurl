### Changed

- **The formal proof can place a callee's body under a call that lifts its regions as bindings of their own** (AGORA-937, stage 3). Any call setting can now be made ghost: its parameter regions are renamed instead of replaced, and only part of the caller's roots is frozen (`RSetup.ghostify`). The result is still a valid setting (`OK.ghostify`, `AbsOK.ghostify`), so the renaming lemma types the callee's body where such a call places it (`StmtT.ren_ghost`). The one new condition is that a borrowed parameter's argument holds no views of the roots left unfrozen. That is what a borrowed parameter's own region will provide. No rule, semantics or theorem statement changes. Compiler, runtime and NURL source are unchanged, so compile time and run time are byte-for-byte as before.
