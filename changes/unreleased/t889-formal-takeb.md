### Added

- **The memory-model proof covers taking an element that owns memory out through a borrow** (AGORA-889). An example is a String popped or removed through `vec_at vv 0` and kept: `: String y ( vec_pop b )`, `( vec_remove b i )`. A new statement of the calculus, `Stmt.takeB`, moves the element out of its owner's tree in place, as the reverse of an element set, to a new owner. It is typed as a truncation through the borrow, so every borrow of the owners' elements ends there. The soundness and leak-freedom theorems cover it, with no axiom and no `sorry`. A witness program (`formal/A2/TakeBWitness.lean`) pops one String and removes another through a borrow, keeps and reads both, and is proven safe and leak-free. Element types that hold views or a destructor value stay outside the claim (`formal/CLAIM.md`).
