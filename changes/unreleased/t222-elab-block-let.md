### Fixed

- **A typed binding of a value block owns what its tail lends of the block's own locals** (Agora #222, stage 1). `: String t { : String a … : String b … ? c a b }` then `^ t` handed back a value its block had already released, and `: V v { : W w ( mkw ) ( view_of w ) }` kept a view of `w`'s freed buffer. A typed `:` binding of a value block is now compiled as the calculus has it: the binding first, owning nothing, then the block with its tail assigned to it before the block's names end. A tail call or a join that lends one of the block's locals is copied into the binding where it does. A value that cannot be copied (a `% Drop` local), or whose type holds a view, is refused, and the message says where to declare the local instead. A copy is made only where the value outlived its source, so programs accepted before keep their code.
