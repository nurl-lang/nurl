### Added

- **certify: a function may take or return a result (`!T E`), so a program that writes a file or opens a connection certifies, conditionally** (AGORA-1044). The translator reads a result type `{ i1, T, E }` as A2's `sum E T` (its error the first variant), and a match on it as `.ite (.isl r)` with the payloads `.getr` / `.getl`, in single-threaded programs as it did in threaded ones. An enum whose variants carry only numbers and that has no destructor (`IoErr`, `NetErr`) is an integer, its tag. A result's literal is still not translated, so a function that builds one, as stdlib's `write_file` and `tcp_connect` do, is not, and a function that calls it is assumed (AGORA-1033): its stub's callees and classes are its real ones (a slot not yet given a value, `let … none`, now classifies). A program whose helper calls `write_file` gets an accepted conditional bundle whose N.cap names `fs.write` through `save → write_file → … → fopen`; one that calls `tcp_connect` and `tcp_close_conn` names `net.connect` (`… → nurl_tcp_connect_ms`) and `net.io` (`… → nurl_tcp_close`). `formal/C/ResultWitness.lean` proves, by the kernel, that the verified checker types such a match (`C.ResultWitness.code_typed`, A2's `FnOK`) and refuses a read of a result's payload after the result moved (`moveThenView_refused`), while the read before the move is typed (`viewThenMove_typed`). `tools/ncore/tolean.py` reads the same, so the two translators still agree on all 4,311 programs `tools/ncore/tolean_parity.sh` compares.

### Fixed

- **certify: a raw string held in an option or a result is refused, not typed as owned text** (AGORA-1044, AGORA-1045). A raw string held in a value is a view of text someone else owns (MEMORY.md §2.13), and a struct field of raw text was already refused for that reason. An option of raw text (`?s`, `{ i1, i8* }`) was translated with an owned payload, `(.sum .int (.vec .int))`, and so is any type holding one (a struct field, a result's member). Both translators (`tolean.nu`, `tools/ncore/tolean.py`) now refuse it, as `a raw string held in an option`, and a result any of whose members holds raw text as `a raw string held in a result`. In the 4,311-program parity corpus this affects two programs that translated before, the hole probes `view_in_option.nu` and `inout_option_holder_given_a_callee_local_view_then_return.nu`: the checker refused both, and they are now unsupported. No certify program changes.
