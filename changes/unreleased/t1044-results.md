### Added

- **certify: a function may take or return a result (`!T E`), so a program that writes a file or opens a connection certifies, conditionally** (AGORA-1044). The translator reads a result type `{ i1, T, E }` as A2's `sum E T` (its error the first variant), and a match on it as `.ite (.isl r)` with the payloads `.getr` / `.getl`, in single-threaded programs as it did in threaded ones. An enum whose variants carry only numbers and that has no destructor (`IoErr`, `NetErr`) is an integer, its tag. A result's literal is still not translated, so a function that builds one, as stdlib's `write_file` and `tcp_connect` do, is not, and a function that calls it is assumed (AGORA-1033): its stub's callees and classes are its real ones (a slot not yet given a value, `let … none`, now classifies). A program whose helper calls `write_file` gets an accepted conditional bundle whose N.cap names `fs.write` through `save → write_file → … → fopen`; one that calls `tcp_connect` and `tcp_close_conn` names `net.connect` (`… → nurl_tcp_connect_ms`) and `net.io` (`… → nurl_tcp_close`). `tools/ncore/tolean.py` reads the same, so the two translators still agree on all 4,311 programs `tools/ncore/tolean_parity.sh` compares.
