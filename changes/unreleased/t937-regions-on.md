### Changed

- **The formal proof's parameter regions are on** (AGORA-937). Two typing rules are relaxed. First, `CallT`'s `ThruFn` premise lets a call into code that changes elements through a borrow pass arguments that hold views, as long as everything they view is a region of the caller's own signature. Second, `FnOK`'s end checks let a function's result or `inout` parameter hold views of a parameter's region. This lets the calculus type a through-changing call that passes a view-holding parameter's own region (`A2/RegionThruWitness.lean`). It also types a function returning views out of its `sink` parameter's elements: one returning its `Vec [s` parameter, whose call leaves the caller's result holding what the argument viewed (`A2/RegionResWitness.lean`). A view of real memory passed to such code is still refused, and so is a function returning a view of its `sink` parameter's own buffer. Where no binding is a region, which is every context the memory invariant is stated of, the call premise is the old one. So the outer call passed no views, every region stands for nothing in its frame, and the lifted inner call passes none. At a call, a region's views become what the argument held, which the caller's result already holds. The crown statement is unchanged. A borrowed result that views a region (a `[s` element returned as `[s`) is not typed yet: `FnOK`'s path check is unchanged. NURL source is unchanged.
