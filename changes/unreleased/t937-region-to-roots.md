### Changed

- **The formal proof shows that a view reached through a parameter's region is reached through the caller's own memory** (AGORA-937, stage 3b, second part). What lands through a dependency on a region lands, at the composed kind, through a dependency on one of the roots the argument holds views of. At the call's entry, the argument's valid views give exactly the hypothesis this needs. So the memory invariant can keep speaking only of the caller's bindings while the body's typing tracks the region as a binding of its own. `formal/A2/THRU_STAGE3_DESIGN.md` takes this route first and keeps the ghost store as a fallback. No typing rule uses it yet, and every theorem statement is as it was. Compiler, runtime and NURL source are unchanged, so compile time and run time are byte-for-byte as before.
