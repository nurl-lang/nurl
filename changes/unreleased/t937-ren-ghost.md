### Changed

- **The formal proof's renaming lemma now holds when a call lifts its parameter regions as bindings of their own** (AGORA-937, stage 3). Until now it assumed that the lift substitutes each region with what its argument holds. It now also holds for a setting that renames each region to a caller-level binding, which is how a call that passes views of the caller's own memory will be typed. A region binding holds an integer's place, and every step keeps that. A call inside the body passes views only of region bindings: none when regions are substituted, and the renamed region when they are not. So a call body placed by either kind of setting is typed where the call places it. No rule, semantics or theorem statement changes. Compiler, runtime and NURL source are unchanged, so compile time and run time are byte-for-byte as before.
