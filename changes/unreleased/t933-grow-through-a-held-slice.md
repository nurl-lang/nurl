### Fixed

- **A callee that grows a `Vec` it reaches through a slice its parameter holds no longer leaves its caller's views of that `Vec` reading freed memory** (AGORA-933). With `vv` a `( Vec ( Slice ( Vec i ) ) )` holding a slice of `w`, a callee that grew `( slice_at ( vec_at vv 0 ) 0 )` (`vec_push`, `vec_reserve`) moved the buffer of `w`'s element, and nurlc did not see it. A view of that element passed beside `vv`, or read by the caller after the call, read freed memory. Now the call refuses a view of that element passed beside `vv` ("… through argument 1, which holds a view of it - an element of which it may grow or move -"), and the caller's own views of it end at the call. Pass a copy of the view that owns its data (`slice_to_vec`) instead, or read the view before the call. NURL source that neither passes such a view beside the holder nor reads one after the call is unchanged.
