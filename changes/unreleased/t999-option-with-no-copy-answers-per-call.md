### Fixed

- **A function that hands back a parameter on one path and a fresh value on another no longer leaks the fresh value when its result is an option or a result with no copy** (AGORA-999). Take `@ maybe ? ( Vec D ) a i k → ?( Vec D ) { ? == k 0 { ^ a } {} ^ ( mk … ) }`, with `D` a `% Drop` type with no copy. Its result was taken as one that always lends, so the caller never dropped the fresh value. Such a result now answers per call whether the caller owns it, as a `( Vec D )` result already did, and the caller drops it on the runs that handed over a fresh value. This holds through a forwarder, in a loop, for an option of an option and for a result type. As for a `( Vec D )`, take a temporary argument the caller owns: a fresh value that no binding holds. A callee that can hand back only that argument, whole, makes the temporary its result, as `( sh ( maybe ( mk … ) 0 ) )` does. A call whose result may instead be part of such a temporary, or one of two arguments, is refused, because the result has no copy to fall back on: bind the argument to a name first, as the error says. A temporary that another call lent is its owner's and is not refused.
