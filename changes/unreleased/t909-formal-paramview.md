### Changed

- **The formal proof covers a destructor that stores a view of its borrowed parameter through a borrow of its own local** (Agora #909's own example, Agora #3932). Before, A2 typed such a store as a change that may reach the caller's memory, so a destructor of a type that holds views doing it was outside the claim. A2 now types it as one that changes only the destructor's own memory when the borrow it stores through is not held-fresh: a call already counts everything its arguments hold as held by that borrow and by every owner a store through it reaches. Take a `% Drop` of `: V { ( Slice i ) s i k }` that pushes `. d s` into `( vec_at loc 0 )` of a local `Vec ( Vec ( Slice i ) )`. nurlc accepts it, it runs clean, and `A2/ParamViewWitness.lean` types it, memory safe and leak-free. This changes the calculus only; NURL source is unchanged. `formal/CLAIM.md` moves the case into the claim.
