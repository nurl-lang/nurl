### Changed

- **The formal proof covers a destructor of a type that holds views when its code changes elements only through a borrow of its own memory** (Agora #909). Before, A2 took such a destructor only for a type that holds no views: a call's setup added everything its arguments hold to every borrow, so any change through a borrow counted as a change of the caller's memory. A2 now records, for each borrow, whether it reaches only memory the frame owns (`Entry.fresh`). It may set this bit for a borrow of a frame's own binding, but never for one of a borrowed parameter. A change through such a borrow reaches no caller memory, and the call passes nothing to it. Take a `% Drop` of `: V { ( Slice i ) s i k }` that pushes through `( vec_at loc 0 )` of a local it made. nurlc accepts it, it runs clean, and `A2/FreshWitness.lean` types it, memory safe and leak-free. This changes the calculus only; NURL source is unchanged. Every program A2 typed before it still types (`A2/Unfresh.lean`). `formal/CLAIM.md` moves the case into the claim. A change through a borrow that may reach caller memory stays outside.
