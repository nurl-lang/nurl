### Changed

- **The formal proof covers a destructor of a type that holds views when its code changes elements only through a borrow of its own memory** (Agora #909). Before, A2 took such a destructor only for a type that holds no views: a call's setup added everything its arguments hold to every borrow, so any change through a borrow counted as a change of the caller's memory. A2 now records, for each borrow, whether it reaches only blocks of the frame's own bindings, never memory an argument views (`Entry.fresh`). It may set this bit for a borrow of a frame's own binding, but never for one of a borrowed parameter. A change through such a borrow cannot change what an argument views, so the call need not treat it as one. Take a `% Drop` of `: V { ( Slice i ) s i k }` that pushes through `( vec_at loc 0 )` of a local it made. nurlc accepts it, it runs clean, and `A2/FreshWitness.lean` types it, memory safe and leak-free. The same holds for a closure that captures a slice and does so (`A2/FreshClosureWitness.lean`). This changes the calculus only; NURL source is unchanged. Each new premise of the calculus holds with the bit off (`A2/Unfresh.lean`), so a program typed before is typed with every bit off. `formal/CLAIM.md` moves the case into the claim. A change through a borrow that is not fresh stays outside, as does a change of elements that hold views.
