### Changed

- **The bundled zig backend is 0.17.1 (LLVM 22)**, up from 0.16.0 (LLVM 21) (Agora #528). The Linux x86_64 and arm64 archives and the Windows x86_64 archive ship it; the CI image, the dev container, the playground image, the fuzz and wasm-bench jobs and wasmbuilder's one-time download use the same version. Every one of those downloads is checked against ziglang.org's own sha256 before it is unpacked, the Windows ones and the three container images included (they checked none before), and `tools/check_pinned_downloads.py` now also reads PowerShell `Invoke-WebRequest` steps, so an unverified Windows download fails CI.

### Fixed

- **`build.sh`, `nurl.sh` and the test runner read IR through a `zig cc` compiler** (Agora #528). zig cc 0.17 refuses `-x ir` ("language not recognized"), so a `CLANG` that wraps `zig cc` failed the opaque-pointer probe on IR it compiles fine, and the `runtime.native.o` step could not lower the runtime bitcode. The probe file is now named `.ll` and the bitcode `.bc`, which every clang and zig cc reads as IR without `-x`.
