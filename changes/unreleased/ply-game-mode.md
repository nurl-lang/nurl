### Added

- **The point-cloud viewer has a game mode** (ply 0.4.1). The "game mode" button, or `g`, flies through a cloud or a 3-D object like a game's spectator camera. The mouse turns the head through a captured cursor, `w a s d` or the arrows move, `e` / `q` rise and sink, shift is faster, and the wheel sets the speed. There is no gravity. `esc` returns to the orbit from the same view. map-anything and lingbot-map serve this viewer, so their result and shared-link pages get it too. It is for mouse and keyboard only; on a touch screen the button is hidden.
