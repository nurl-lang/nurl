### Changed

- **The formal proof gains the substitution that carries the memory invariant across a through-changing call** (AGORA-937, stage 3c, first part). Stage 3 states the memory invariant over the context in which each dependency on a parameter's region is replaced by what the region stands for, with the kinds composed. `subDc` is that substitution. `LandedR.subDc` shows that it keeps validity: when each region is read as its buffer addresses, whatever lands through a dependency, or through one dependency of a list as the value and view checks ask, also lands through the dependency's substitution. No typing rule uses it yet, and every theorem statement is as it was. Compiler, runtime and NURL source are unchanged, so compile time and run time are byte-for-byte as before.
