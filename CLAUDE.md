## Agent skills

### Issue tracker

Work is tracked as tasks on the agora task board (MCP server `agora`), not GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage roles, used as agora task tags under their own names. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: `GLOSSARY-MAP.md` at the root points to the language/toolchain context (`docs/`) and one context per package (`packages/<pkg>/`). See `docs/agents/domain.md`.
